# 面试复盘提示词合集

## 1. 面试完整还原引导

```
请帮我复盘这场面试。我会提供面试回忆，你帮我按以下结构整理：

1. 面试基本信息：公司/岗位/轮次/时长
2. 问题清单：每个问题 + 我的回答摘要 + 面试官反应
3. 自我感觉：哪里答得好、哪里卡壳、哪里紧张
4. 面试官追问点：追问了什么（= 可能没答到点上）

请先不要评判，帮我客观还原。还原后再做诊断。
```

## 2. 漏斗诊断

```
请根据以下求职数据诊断我的转化率短板：

- 投递简历数：{applied}
- 获得面试数：{interviews}
- 一面通过数：{first_pass}
- 二面通过数：{second_pass}
- 终面通过数：{final_pass}
- Offer 数：{offers}

请计算各层转化率，对比行业均值（简历→面试 20%、一面通过 35-40%、二面通过 30-35%、终面通过 70-80%），定位最低于均值的环节，给出根因假设和验证方法。
```

## 3. 短板分类与改进

```
请根据以下面试复盘，对问题进行分类并给出改进方案：

【面试复盘记录】
{retro_notes}

请按以下格式输出：
1. 显性短板（不会的知识点）：清单 + 学习方法 + 验证标准
2. 隐性短板（没深度/没数据）：清单 + 改进方法 + 验证标准
3. 表达短板（说不清楚）：清单 + 练习方法 + 验证标准
4. 匹配短板（没让面试官感知到）：清单 + 调整策略

每个短板给出优先级（P0/P1/P2），P0 问题必须在下一场面试前解决。
```
