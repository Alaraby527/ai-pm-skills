# 视觉系统：令牌、动效、画面模式

目标不是好看，是**在 4 秒内让人看懂一件事**。下面的参数可直接拄，数字都在 1080p 实测过。

## 一、三套主题令牌

选定一套，写进代码的单一位置（HyperFrames 放 `:root`，Remotion 放 `theme.ts`），之后只改令牌不改组件。

### A. 深色知识（默认，适合科普 / 数据 / 技术解读）

```
ground    #08090A   近黑，不用纯黑，留一点层次
ink       #EBE5D8   米白正文，比纯白柔和
inkDim    #8C9099   次要信息，不要再暗
gold      #DEB78D   强调 / 关键数字，占画面不超过 15%
steel     #91AEBB   结构线 / 次级强调
line      #243038   网格与分隔线，加 30%-50% 透明度用
serif     Noto Serif SC    标题
sans      Noto Sans SC     正文
mono      JetBrains Mono   眉批 / 数字 / 时间码
```

### B. 浅色编辑（适合品牌内容 / 教学 / 商务汇报）

```
ground    #F5F2EA   纸感米白
ink       #16180F
inkDim    #6B6A60
accent    #B5462E   砖红
secondary #3B6B5A   墨绿
line      #DAD5C6
```

浅底上的结构线不要用细白线，改用同色系深一档的实线；阴影一层 `rgba(0,0,0,0.06)` 就够。

### C. 品牌定制

从上往下替换：主色 → 辅助色 → 底色 → 字体。品牌色只做强调，不做大面积填充，否则文字对比度必崩。

## 二、版式常量（1920×1080）

| 项 | 值 | 说明 |
|---|---|---|
| 安全边 | 96px | 四边都留，平台裁切也安全 |
| 内容栏宽 | 980px（左栏）/ 1728px（整幅） | 左对齐内容不要超过 980 |
| 标题字号 | 96-120（封面）/ 56-72（场景） | 中文比拉丁文再大 1 档 |
| 正文字号 | 30-36 | 行高 1.7-1.8 |
| 眉批字号 | 20-24 mono | 字距 0.2-0.34em，全大写 |
| 数据大字 | 140-220 | 只放一个数，周围留白 |
| 字幕字号 | 26-30 | 距底 120-160px |

9:16（1080×1920）：安全边 72px，标题 72-88，正文 28-32，字幕距底 280px 以避开平台 UI。

## 三、动效参数

| 动作 | 时长 | 曲线 | 附加 |
|---|---|---|---|
| 标题入场 | 0.7-0.9s | `power3.out` | y 40→0，blur 10→0 |
| 次要元素依次入场 | 每项间隔 0.15-0.25s | `power2.out` | y 24→0 |
| 线条生长 | 0.6-1.4s | `power2.inOut` | `scaleX` 0→1，原点在左 |
| 节点出现 | 0.5-0.55s | `power2.out` | opacity + 轻微位移 |
| 强调闪一下 | 0.2-0.25s | `power4.out` | 只动 opacity / 亮度 |
| 退场 | 0.35-0.5s | `power2.in` | y → -20~-30，blur 0→8 |
| 进度 / 计时 | 全片 | 线性 | 不要缓动 |
| 转场留白 | 0.4s | — | 旧内容退完，新内容再进 |

不要做的事：

- 全屏缩放超过 1.1，会眶。
- spring 的 `damping` 低于 12，弹得像玩具；稳妥值 18-20。
- 每个元素都加动效。一屏最多 3 个入点。
- 用旋转和 3D 做高级感。在信息型视频里它是噪音。

## 四、画面模式库

七个模式能覆盖多数信息型镜头。每个都写了什么时候用、怎么动。

### 1. 大标题（封面 / 结尾）

结构：眉批（mono 小字）→ 主标题（serif 大字，最多 2 行）→ 副标题（sans 灰字）→ 一条细纹光线。
动效：眉批先入，标题随后（blur + y），线最后从左生长。
适用：开篇 3 秒钩子、结尾落点。一屏只放一句话。

### 2. 关系图（人 / 物 / 概念之间）

结构：2-3 个圆形或方形节点 + 连线 + 每个节点下方一行小注。
动效：节点依次出现（间隔 0.2s），连线用 `attr: x2` 或 `scaleX` 生长，最后出总结句。
适用：解释机制、角色分工、因果链。超过 5 个节点换流程图或分屏。

### 3. 对比双栏（A vs B）

结构：中间一纹竖线，左右各一栏，每栏顶部标签 + 3 条以内要点。
动效：左栏先入，竖线生长，右栏后入（间隔 0.35s），差异项用强调色标出。
适用：新旧方案、两种观点、前后状态。

### 4. 数据条（数字说明）

结构：一个巨大数字 + 单位 + 一行注释；或 3-5 条横向条形图。
动效：数字滚动（按帧号取整输出），条形 `scaleX` 生长，注释最后淡入。
适用：增长率、份额、规模。数字必须有出处，宁可说约数也不要编。

### 5. 引文（观点定格）

结构：居中 serif 大字，最多 2 行，下面一行小字署名或补充。
动效：blur 12→0 配 scale 0.97→1，慢一点，0.9-1.1s。
适用：章节之间的呼吸点、结尾升华。全片最多 2 次。

### 6. 流程 / 时间线

结构：横向 3-5 步，步与步之间箭头或短横线，当前步高亮。
动效：整体先淡入，再逐步点亮（间隔 0.3s），高亮用强调色 + 1.05 倍缩放。
适用：操作步骤、发展历程、决策路径。

### 7. 章节页（超短过场）

结构：一个序号（mono 大字）+ 一个词（serif）+ 一条线，全屏留白 70%。
动效：0.4s 内全部到位，停留不超过 1.5s。
适用：长片分章。短片不要用，浪费时长。

## 五、自检：这一屏合格吗

- 眶眼看，第一落点是不是你要让人记住的那个东西？
- 屏幕上字数不超过 20（不含字幕）。超了就是没提炼。
- 关掉颜色看灰度，结构还在不在？
- 把这一帧当封面图发出去，能不能独立看懂？
- 动效删掉一半，信息有没有损失？没有损失就删。
