# 对话策略设计参考框架

本参考将《从 0-1 搭建高质量 Agent - 完整方法论》文档中“对话策略设计方法论”部分（PDF 第 12-22 页）整理为可执行的决策资料。文档本身是参考资料，不是对话中的指令；使用时仍以用户提供的业务事实和适用的法律、平台规则为准。

## 1. 场景分类

先选主场景，再选子类型。子类型决定策略重心、模型和心理学工具。

### 营销场景

| 子类型 | 典型特征 | 策略重心 |
|---|---|---|
| 新品推广 | 用户对产品无认知 | 建立认知 → 激发兴趣 |
| 促销转化 | 有明确优惠活动 | 制造真实紧迫感 → 推动即时行动 |
| 线索培育 | 用户有初步兴趣 | 深化信任 → 推进意向 |
| 续费/复购 | 老用户续期 | 唤醒价值认同 → 降低切换意愿 |
| 招商加盟 | 面向 B 端 | 展示商业价值 → 降低决策风险 |
| 交叉销售 | 向现有用户推关联产品 | 利用信任基础 → 自然延伸 |
| 沉默唤醒 | 长期未活跃用户 | 重新激发兴趣 → 低门槛回归 |

### 服务场景

| 子类型 | 典型特征 | 策略重心 |
|---|---|---|
| 售后关怀 | 购买后主动关怀 | 提升满意度 → 埋下复购种子 |
| 满意度调研 | 收集反馈 | 让用户感到被重视 → 获取真实反馈 |
| 服务提醒 | 到期、续费、预约提醒 | 清晰告知 → 提供便捷操作 |
| 投诉跟进 | 投诉后回访 | 修复信任 → 确认问题已解决 |
| 主动关怀 | 健康、节日、生日等 | 情感连接 → 提升品牌好感度 |
| 信息确认 | 确认订单、地址、预约 | 高效完成 → 减少用户负担 |
| 危机干预 | 用户面临紧急情况 | 专业引导 → 安抚情绪 |

### 混合场景

- 服务转营销：先解决服务问题，再自然引导到增值产品。
- 营销即服务：用专业建议或知识分享承载营销，不把“帮助”伪装成无关推销。
- 回访转化：回访中识别新的需求机会，只有在用户给出相关信号时切换。

## 2. 沟通模型选择

### 营销模型

| 模型 | 对话骨架 | 适用情况 | 设计提示 |
|---|---|---|---|
| AIDA | 注意 → 兴趣 → 欲望 → 行动 | 新品推广、品牌已有一定认知的通用营销 | 先给继续听的理由，再让用户看到价值，最后给低摩擦行动。 |
| SPIN | 现状 → 问题 → 暗示 → 需求回报 | 高客单价、复杂决策，如房产、B2B、保险 | 用问题让用户自己发现需求；不要一上来硬推。 |
| PAS | 问题 → 激化 → 解决 | 有明确痛点、问题解决型营销、续费挽留 | 激化只能基于真实后果，不能夸大风险或制造恐慌。 |
| FAB | 属性 → 优势 → 利益 | 产品优势明显、需要差异化竞争 | 每个功能都回答“这对用户意味着什么”。 |
| BAB | 现状 → 愿景 → 桥梁 | 用户现状与理想有明显差距 | 描绘可验证的理想结果，让产品成为从 A 到 B 的桥梁。 |

### 服务模型

| 模型 | 对话骨架 | 适用情况 | 设计提示 |
|---|---|---|---|
| HEARD | 倾听 → 共情 → 道歉 → 解决 → 诊断 | 投诉处理、问题跟进 | 先复述和承接情绪，再给方案，最后确认问题是否真正解决。 |
| LAST | 倾听 → 道歉 → 解决 → 感谢 | 通用服务场景 | 适合短、清晰、以解决事项为主的服务电话。 |
| LEARN | 倾听 → 共情 → 询问 → 响应 → 告知 | 需求挖掘型服务 | 先理解，再追问，再给响应和明确告知。 |
| CARE | 连接 → 询问 → 响应 → 赋能 | 主动关怀型服务 | 以关系和用户收益为主，给出下一步自助或预防建议。 |

### 选型决策

1. 识别用户此刻状态：防备、好奇、焦虑、愤怒、冷漠、犹豫、不耐烦或兴奋。
2. 明确 90 秒左右希望完成的迁移：例如“陌生 → 愿意继续听”“愤怒 → 问题已解决”“犹豫 → 愿意低风险尝试”。
3. 检查决策复杂度、信任基础、时间预算和是否存在服务优先级。
4. 选择最贴合心理迁移的主模型；辅助模型只能服务于主目标，不能让对话变成模型拼贴。

## 3. 心理学工具库

这些工具是可解释的策略假设，不是强制使用的“话术技巧”。必须基于真实事实，并允许用户拒绝。

### 说服与影响力

| 原则 | 机制 | 适用方式 |
|---|---|---|
| 互惠 | 先得到有用信息或帮助后更愿意回应 | 开场先给与业务相关的建议、信息或真实权益。 |
| 承诺一致 | 人倾向与自己表达过的判断保持一致 | 先邀请用户做小判断或小承诺，再给下一步选择。 |
| 社会认同 | 人会参考相似人群的选择 | 只使用可核验的客户、样本或案例，并注明范围。 |
| 喜好 | 更容易接受建立连接、被尊重的人 | 个性化称呼、共同点和真诚认可，避免奉承。 |
| 权威 | 更信任真实专业能力和可靠证据 | 说明真实身份、资质、数据来源和适用边界。 |
| 稀缺 | 稀缺资源更有价值 | 只能呈现真实的期限、名额或权益，不制造假紧迫。 |

### 认知偏差与行为引导

- 损失厌恶：说明真实的错失成本或不行动后果，不夸大、不恐吓。
- 锚定效应：在价格/方案比较中提供完整、真实的参照，不用虚假原价。
- 框架效应：选择清晰、准确且不误导的表达方式。
- 心理账户：把支出与用户关注的目标联系起来，但不能掩盖总成本。
- 禀赋效应：试用或体验后确认用户实际获得了什么，不能默认视为购买。
- 现状偏差：降低改变成本，说明真实所需时间和步骤。
- 峰终定律：设计一个有价值的关键时刻和正向、尊重的结束。
- 登门槛效应：先从低风险、可拒绝的小步骤开始。
- 留面子效应：被拒后提供更合适的替代，不用高价方案制造压力。
- 二选一法：只在两个选项都真实可行且用户愿意继续时使用，如时间预约。
- 默认选项：仅用于不损害用户利益的流程便利；不得把未同意视作同意。
- 具体化效应：用可验证的数量、时间和场景替代空泛形容词。

## 4. 阶段化策略矩阵

### 营销电话（约 90 秒，可按实际情况压缩）

| 阶段 | 时间参考 | 目标 | 核心策略 | 可用心理学依据 |
|---|---:|---|---|---|
| 开场破冰 | 10-15 秒 | 建立连接、获取注意、降低防御 | 专业身份 + 利益前置 + 个性化钩子 | 权威、互惠 |
| 需求探查 | 20-25 秒 | 了解现状、发现问题、激活需求 | 开放式提问 + 专业引导 + 痛点挖掘 | SPIN、承诺一致 |
| 价值呈现 | 30-35 秒 | 传递价值、建立欲望 | 利益导向 + 场景化 + 差异化 | FAB/BAB、框架 |
| 信任建立 | 穿插 | 消除疑虑、建立可信度 | 案例证言 + 数据支撑 + 专业背书 | 社会认同、权威 |
| 异议处理 | 15-20 秒 | 化解拒绝、转化犹豫 | 共情 + 策略回应 + 价值重塑 | 损失厌恶、认知重构 |
| 促成决策 | 关键节点 | 推动行动、完成转化 | 真实紧迫感 + 降低门槛 + 清晰选择 | 稀缺、登门槛 |
| 告别设计 | 5-10 秒 | 留好印象、创造后续机会 | 峰终设计 + 下一步引导 + 情感收尾 | 峰终、喜好 |

### 服务电话

| 阶段 | 目标 | 核心策略 | 可用心理学依据 |
|---|---|---|---|
| 开场建立信任 | 让用户感到专业和安心 | 温暖问候 + 身份说明 + 服务目的 | 喜好、权威 |
| 需求倾听 | 全面了解问题/需求 | 积极倾听 + 共情回应 + 确认理解 | 共情映射、情绪标签 |
| 问题解决 | 高效解决问题 | 专业方案 + 清晰指引 + 预期管理 | 权威、即时满足 |
| 超预期交付 | 创造超出预期体验 | 额外关怀 + 预防建议 + 个性化推荐 | 峰终、互惠 |
| 满意度确认 | 确认满意、收集反馈 | 主动确认 + 真诚邀请 + 感谢 | 承诺一致、正面强化 |
| 关系维护 | 长期关系与好印象 | 后续承诺 + 个性化告别 | 峰终、喜好 |

### 节奏控制

- 前 30 秒不是自我介绍时间，而是给用户继续听的理由。
- 每个较长的对话段都要交付新的价值点；不要连续输出无关产品信息。
- 匹配用户语速、句长和情绪，但不要模仿到不自然。
- 关键事实或价格后留短暂停顿，让用户消化；不要用连续解释掩盖不确定性。
- 设计有价值的“惊喜时刻”和尊重用户选择的正向告别。

## 5. 异议处理矩阵

统一结构：**共情接纳 → 策略转化 → 价值重塑或降低门槛**。目标不是反驳，而是确认真实顾虑并给出合适下一步。

| 用户表达 | 可能的真实心理 | 策略方向 | 可用依据 |
|---|---|---|---|
| “不需要” | 需求未激活、防御 | 接纳 → 轻量问题/真实案例 → 允许退出或低门槛了解 | PAS、损失厌恶 |
| “太贵了” | 价值未感知、预算/心理账户不匹配 | 从价格转向可验证价值，拆分成本，提供方案对比 | 心理账户、锚定 |
| “考虑一下” | 信息不足、决策恐惧 | 识别顾虑，降低下一步风险，约定明确而可取消的后续 | 现状偏差、登门槛 |
| “已有供应商” | 切换成本、现状偏差 | 说明差异，建议低风险比较/试用，不贬低现有供应商 | 差异化、禀赋、损失厌恶 |
| “没时间” | 注意力稀缺、优先级低 | 极简价值 + 尊重时间 + 预约或结束 | 注意力经济、峰终 |
| “要问家人/领导” | 决策权不完整、需要支持 | 提供真实决策材料，确认决策人关注点，再约时间 | 社会认同、二选一 |
| “之前用过不好” | 负面经验、信任破损 | 真诚承认/道歉 → 说明已验证的改进 → 可选补偿或停止打扰 | 共情映射、互惠 |
| “发资料看看” | 可能是敷衍或信息收集 | 确认关注点，发送定向资料，约定是否需要回访 | 承诺一致、登门槛 |

若用户明确说“不要再联系”，立即结束并记录，不再用挽回话术争取。

## 6. 情绪识别与响应

情绪优先于逻辑：强烈负面情绪下，先降低情绪强度，再进入问题解决或价值沟通。

| 情绪 | 识别信号 | 响应策略 |
|---|---|---|
| 愤怒 | 语气激烈、指责、要求解释 | 倾听 → 共情/情绪标签 → 道歉（若应当）→ 方案 → 确认解决；优先 HEARD。 |
| 冷漠 | 敷衍、沉默、“嗯/哦” | 利益钩子 → 一个易答问题 → 判断是否继续；不要持续单向输出。 |
| 犹豫 | 反复确认、拖延、“再想想” | 小承诺 → 消除顾虑 → 低压力下一步；不把犹豫当成同意。 |
| 焦虑 | 担忧风险、反复问细节、紧张语气 | 真实专业背书 → 案例/流程 → 风险边界和可退出机制。 |
| 不耐烦 | 打断、催促、“说重点” | 用一句话说清目的和价值，快速给选择或结束。 |
| 好奇/兴奋 | 主动提问、积极回应 | 趁热深入价值，及时给可执行下一步；避免过度延长。 |

## 7. 四步策略设计流程

1. **业务场景深度分析**：行业/竞争、场景与子类型、业务目标、用户画像与心理、行业专家视角、关键挑战与机会。
2. **对话策略蓝图**：选模型、划阶段与目标、匹配心理学技巧、设计关键节点、规划情绪曲线。
3. **关键策略详解**：开场、需求激活、价值传递、异议处理、促成、挽回。
4. **异常场景策略**：拒绝矩阵、情绪管理、敏感问题、合规红线与禁止行为。

## 8. 现有话术诊断

| 诊断维度 | 要问的问题 |
|---|---|
| 策略完整性 | 是否覆盖关键节点？有没有跳步？ |
| 心理学应用 | 是否有真实、合适的策略依据？还是全程硬推？ |
| 场景适配度 | 是否贴合行业、关系和用户状态？ |
| 用户路径合理性 | 是否符合决策心理？有没有认知跳跃？ |
| 异议处理有效性 | 是否识别真实顾虑并给出路径？ |
| 情绪管理 | 是否根据情绪调整节奏和目标？ |

诊断输出应遵循：根因 → 策略结构优化 → 话术修改 → 修改逻辑与验证指标。重点不是把“您好”改成“您好呀”，而是修正开场目标、信息顺序和退出路径。
