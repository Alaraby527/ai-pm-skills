# AI 产品专项指标体系模板

## 使用说明

AI 产品在传统业务指标（L1/L2）之外，必须监控 AI 质量层（L3）和系统健康层（L4）指标。本模板提供 AI 产品常用指标定义、测量方式和目标值参考。

---

## L3 AI 质量指标

### 1. 准确性指标

| 指标 | 定义 | 测量方式 | 目标值参考 |
|------|------|---------|-----------|
| 准确率（Accuracy） | AI 输出正确的比例 | 人工标注评测集 / 自动评测 | ≥ 90%（视场景） |
| 精确率（Precision） | AI 给出的答案中正确的比例 | TP / (TP + FP) | 高风险场景 ≥ 95% |
| 召回率（Recall） | 应返回的结果中实际返回的比例 | TP / (TP + FN) | 搜索/推荐场景 ≥ 85% |
| F1 Score | 精确率和召回率的调和平均 | 2 × P × R / (P + R) | 综合评估 |

### 2. 可靠性指标

| 指标 | 定义 | 测量方式 | 目标值参考 |
|------|------|---------|-----------|
| 幻觉率（Hallucination Rate） | AI 编造不存在信息的比例 | 人工抽检 / 事实一致性检测 | ≤ 5% |
| 忠实度（Faithfulness） | RAG 回答基于检索内容的比例 | 回答与检索 chunks 的一致性评分 | ≥ 90% |
| 拒答率（Refusal Rate） | AI 拒绝回答的比例 | 日志统计 | 区分合理拒答 vs 过度拒答 |
| 一致性（Consistency） | 相同问题多次回答的一致程度 | 重复提问对比 | ≥ 85% |

### 3. 用户体验指标

| 指标 | 定义 | 测量方式 | 目标值参考 |
|------|------|---------|-----------|
| 采纳率（Adoption Rate） | 用户采纳 AI 建议/输出的比例 | 点击"采用"/"复制"埋点 | ≥ 40% |
| 人工干预率 | AI 输出后被人工修改的比例 | 修改行为埋点 | ≤ 20% |
| 重新生成率 | 用户对 AI 输出不满意重新生成的比例 | "重新生成"按钮埋点 | ≤ 30% |
| Bad Case 率 | 用户标记"不好"的比例 | 反馈按钮统计 | ≤ 5% |
| AI 满意度 | 用户对 AI 输出的主观评分 | 点赞/点踩 / 评分弹窗 | ≥ 4.0/5.0 |

### 4. 场景专项指标

| 场景 | 专项指标 | 说明 |
|------|---------|------|
| 智能客服 | 解决率、转人工率、首响时间 | 解决率 = 无需人工介入的比例 |
| 内容生成 | 一次通过率、编辑距离、发布率 | 一次通过 = 无需修改直接使用 |
| 搜索/RAG | 点击率、零结果率、首条命中率 | 首条命中 = 第一条结果即满足需求 |
| 推荐系统 | 点击率、转化率、多样性、覆盖率 | 注意信息茧房 |
| Agent 任务 | 任务完成率、平均步数、工具调用成功率 | 多步骤任务的端到端完成率 |

## L4 系统健康指标

| 指标 | 定义 | 目标值参考 |
|------|------|-----------|
| P50 响应时长 | 50% 请求的响应时间 | < 2s |
| P95 响应时长 | 95% 请求的响应时间 | < 5s |
| P99 响应时长 | 99% 请求的响应时间 | < 10s |
| 错误率 | 请求失败的比例 | < 1% |
| 可用性 | 系统正常服务时间比例 | ≥ 99.9% |
| Token 消耗 | 单次请求/日/月的 Token 用量 | 按成本预算 |
| 并发处理能力 | 同时处理的请求数 | 按业务峰值 |

## 指标看板设计建议

1. **分层展示**：L1 业务指标 → L2 行为指标 → L3 AI 质量 → L4 系统健康，逐层下钻
2. **关联分析**：AI 质量指标（L3）变化时，自动关联业务指标（L1）变化，判断影响
3. **Bad Case 闭环**：Bad Case 率升高 → 自动采样 → 人工标注 → 归因 → 优化 → 回归
4. **版本对比**：模型/Prompt 更新后，新旧版本指标对比看板
5. **告警阈值**：幻觉率 > 10%、错误率 > 5%、P95 > 8s 触发告警
