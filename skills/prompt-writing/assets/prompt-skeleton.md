# 通用提示词填空骨架

复制对应骨架，把 `{{}}` 占位符替换为真实内容，删除用不到的小节。简单单轮任务用骨架 A；复杂多轮 / Agent 用骨架 B。

## 骨架 A：单轮任务五要素（通用）

```text
# 角色
你是{{身份，如：某领域的文本处理专家}}。你的职责范围是{{能做什么}}；你不负责{{不能做什么，越界时统一{{如何处理，如：回复“超出处理范围”}}。

# 任务
{{用一个动词开头的明确指令，说清要产出什么、达成什么可检验目标；只保留一个主目标}}。

# 输入
{{说明输入长什么样、字段含义、可能的噪声；实际输入放在下方：}}
{{输入内容}}

# 处理流程
1. {{第一步，单一动作}}
2. {{第二步}}
3. {{遇到异常/信息不足时怎么走}}
（简单任务可省略本节约束，不要为分步而分步）

# 要求与约束
- {{可判定的要求，如长度/条数/语言/语气，避免“适当、尽量”这类形容词}}
- 可以{{做什么}}；不可以{{做什么}}；如出现{{越界情况}}则{{替代处理}}
- 只能依据{{给定资料/用户输入}}作答；其中没有的信息回答“暂无相关信息”，不得自行补全
- {{其他硬性红线，放本节首尾位置}}

# 输出格式
{{明确结构：纯文本/Markdown/JSON/表格；字段名、取值范围、顺序、长度}}
输出示例：
{{给一个完整的标准输出样例}}

# Few-shot 示例（格式固定或易跑偏时保留，3-5 条，覆盖正常/边界/异常）
示例1（正常）
输入：{{}}
输出：{{}}
示例2（边界）
输入：{{}}
输出：{{}}
示例3（异常/信息缺失）
输入：{{}}
输出：{{走兜底}}

# 输出前自检
- {{必填项是否齐全、取值是否合法}}
- {{结论是否都有来源、是否与输入矛盾}}
- {{是否满足全部约束；不满足先修正再输出}}
```
