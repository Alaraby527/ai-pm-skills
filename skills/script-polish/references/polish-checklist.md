# 逐字稿打磨检查清单

## 6 类问题诊断表

| # | 问题类型 | 检查项 | 常见表现 | 严重程度 |
|---|---------|--------|---------|---------|
| 1 | 结构缺失 | 开头是否结论先行？ | 听了 30 秒还不知道重点 | P0 |
| | | 是否有清晰的分段？ | 一段话讲完所有内容 | P0 |
| | | 结尾是否有总结/升华？ | 讲完就结束，没有收尾 | P1 |
| 2 | 数据缺失 | 核心论点有数字吗？ | "提升了很多""效果不错" | P0 |
| | | 数据有对比基线吗？ | "DAU 10 万"但不说之前是多少 | P1 |
| 3 | 逻辑跳跃 | 因果关系成立吗？ | "我做了 X，然后成功了"（缺中间过程） | P0 |
| | | 有决策依据吗？ | 只说做了什么，不说为什么这么做 | P0 |
| | | 有权衡取舍吗？ | 只说方案好，不说放弃了什么 | P1 |
| 4 | AI 味/套话 | 有"赋能/抓手/闭环"吗？ | 堆砌行业黑话但没有具体内容 | P1 |
| | | 有"首先/其次/最后"吗？ | 过度结构化，像背书不像说话 | P2 |
| 5 | 口头禅/冗余 | "嗯""然后""就是说"多吗？ | 每句话都以"然后"开头 | P1 |
| | | 有重复表述吗？ | 同一个观点说 2-3 遍 | P1 |
| 6 | 负面表达 | 有抱怨前公司/同事吗？ | "前公司太烂了""领导不懂" | P0 |
| | | 有过度自谦吗？ | "我只是做了…""我运气好…" | P1 |

## 四段式结构检查

| 段落 | 占比 | 检查项 |
|------|------|--------|
| 结论先行 | 10% | 一句话说清核心答案 |
| 数据支撑 | 30% | 至少 2 个具体数字/案例 |
| 逻辑推导 | 40% | 思考过程 + 决策依据 + 权衡取舍 |
| 复盘升华 | 20% | 学到了什么 + 可复用方法论 |

## 口语化检查

- [ ] 句子平均长度 ≤ 20 字
- [ ] 没有长难句/书面语
- [ ] 有自然过渡词（"第一…""这里关键是…""结果是…"）
- [ ] 数字用口语表达（"增长了 50%"而非"提升了 50 个百分点"）
- [ ] 读出来不拗口
- [ ] 保留了个人说话风格，不是播音腔

## 时长版本检查

| 版本 | 时长 | 字数参考 | 内容要求 |
|------|------|---------|---------|
| 电梯版 | 30 秒-1 分钟 | 100-200 字 | 结论 + 1 个数据 + 1 个亮点 |
| 标准版 | 3 分钟 | 500-700 字 | 结论 + 背景 + 方案 + 结果 + 一句话复盘 |
| 深挖版 | 5-8 分钟 | 1000-1500 字 | 完整四段式 + 决策细节 + 踩坑 + 复盘 |

## 评分表

| 维度 | 1-3 分 | 4-6 分 | 7-8 分 | 9-10 分 |
|------|--------|--------|--------|---------|
| 结构 | 没有重点 | 有结构但不清晰 | 结构清晰 | 结构精巧，引人入胜 |
| 数据 | 全是定性描述 | 有数字但无对比 | 有数据有对比 | 数据驱动，有说服力 |
| 逻辑 | 跳跃严重 | 基本连贯 | 逻辑通顺 | 逻辑严密，有深度 |
| 表达 | 口头禅多/书面化 | 基本自然 | 自然流畅 | 有个人魅力 |
| 复盘 | 无复盘 | 有但浅 | 有认知升级 | 有方法论沉淀 |
