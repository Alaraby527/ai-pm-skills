# 逐字稿打磨提示词合集

## 1. 逐字稿诊断

```
请诊断以下面试逐字稿的表达问题：

【面试问题】
{question}

【逐字稿原文】
{transcript}

请按 6 类问题逐句检查：
1. 结构缺失（没有结论先行、重点不突出）
2. 数据缺失（全是定性描述没有数字）
3. 逻辑跳跃（因果关系不成立、缺推导过程）
4. AI 味/套话（"赋能""抓手""闭环"等堆砌）
5. 口头禅/冗余（"嗯""然后""就是说"过多、重复）
6. 负面表达（抱怨、甩锅、过度自谦）

对每个问题标注：原文位置 + 问题类型 + 修改建议。
最后给出整体评分（1-10）和最需要改的 3 个点。
```

## 2. 回答结构重构

```
请按四段式重构以下面试回答：

【面试问题】
{question}

【原始回答】
{original_answer}

四段式结构：
1. 结论先行（10%）：一句话核心答案
2. 数据支撑（30%）：具体数字、案例
3. 逻辑推导（40%）：思考过程、决策依据、权衡取舍
4. 复盘升华（20%）：学到了什么、可复用方法论

要求：口语化、短句、有过渡词、读起来像说话不是背书。
```

## 3. 多版本时长控制

```
请将以下回答改写成 3 个时长版本：

【原始回答】
{answer}

1. 电梯版（30 秒-1 分钟）：结论 + 1 个核心数据 + 1 个亮点
2. 标准版（3 分钟）：结论 + 背景 + 方案 + 数据结果 + 一句话复盘
3. 深挖版（5-8 分钟）：完整四段式 + 决策细节 + 踩坑经验 + 复盘认知

每个版本标注预计时长。
```

## 4. 口语化打磨

```
请将以下书面化回答改成自然口语：

【书面版本】
{written_text}

要求：
- 长句拆短（一句话不超过 20 字）
- 书面语改口语（"基于上述分析"→"所以我当时判断"）
- 增加自然过渡词（"第一…第二…""这里有个关键决策…"）
- 去除口头禅但保留个人风格
- 数字口语化
- 不要"播音腔"，要像真实面试中的自然表达
```
