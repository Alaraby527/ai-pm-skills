# 竞品信息卡模板
> 阶段二（信息采集）使用。每个竞品一张，一次填全，后续阶段反复引用。

## 竞品信息卡

| 字段 | 填写内容 | 说明 |
|------|---------|------|
| 产品名称 | | 官方名称 |
| 网站链接 | | 首页 URL |
| 所属公司 | | 运营主体 |
| 上线时间 | | 或重大改版时间 |
| 目标用户 | | 核心用户画像描述 |
| 核心价值主张 | | 首页 slogan 或产品定位一句话 |
| 盈利模式 | | 广告 / 订阅 / 交易佣金 / 增值服务等 |
| 竞品类型 | | 直接 / 间接 / 标杆 |
| 入选理由 | | 为什么选它 |
| 用户规模参考 | | 如有公开数据则记录，附来源链接 |

## 填写要点
- "目标用户"不要只写"年轻人"，要写到角色+场景+痛点，如"25-35岁职场人，用于碎片化学习，痛点是课程太笼统"
- "核心价值主张"优先用官网原文，不要自己概括
- "用户规模参考"必须附来源链接和时间，检索不到写"未找到公开信息"
- 同一批竞品的信息卡字段保持一致，便于横向对比
