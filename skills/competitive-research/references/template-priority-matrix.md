# 优先级评估与综合对比模板
> 用于 Step 5（SWOT 与战略象限）和 Step 6（输出结论）。将功能差距 + 交互问题合并，按三维模型排序优先级，输出可执行的优化建议。

## 一、综合对比矩阵
> 将功能差距清单和交互问题清单合并，按功能模块组织，每个模块同时展示功能覆盖差距和交互设计差距。

| 功能模块 | 功能覆盖 | 功能深度 | 交互质量 | 综合判断 |
|---------|---------|---------|---------|---------|
| 用户体系 | 领先/持平/落后 | x/5 分 | x/5 分 | |
| 核心业务 | | | | |
| 搜索与发现 | | | | |
| 互动与社交 | | | | |
| 交易与支付 | | | | |
| 通知与消息 | | | | |
| 辅助功能 | | | | |

**综合判断规则：** 不是简单取平均，而是结合功能权重和交互影响度做整体评价。某模块即使其他维度尚可，若功能覆盖落后+深度和交互都只有 2 分，该模块短板会拖累整体体验。

## 二、优先级三维评估模型
> 优先级不是单纯看问题大小，而是综合影响和成本。三个维度各评高/中/低，综合后分四级。

| 评估维度 | 说明 | 高分特征 |
|---------|------|---------|
| 用户影响度 | 影响多少用户、对核心任务完成有多大阻碍 | 高频且阻碍核心流程 |
| 竞争紧迫度 | 该差距是否是竞品的核心卖点 | 竞品正以此功能差异化宣传 |
| 实现成本 | 修复需要多少研发资源 | 功能缺失通常成本高于交互优化 |

| 优先级 | 定义 | 典型组合 |
|--------|------|---------|
| P0 | 立即启动 | 用户影响高 + 竞争紧迫高 + 成本中低 |
| P1 | 下版本纳入 | 用户影响中高 + 竞争紧迫中 + 成本可控 |
| P2 | 排入规划 | 用户影响中 + 竞争紧迫低 + 成本低 |
| P3 | 持续观察 | 用户影响低 + 竞争紧迫低 |

| 优先级 | 问题描述 | 差距类型 | 用户影响度 | 竞争紧迫度 | 实现成本 | 建议动作 |
|--------|---------|---------|-----------|-----------|---------|---------|

| P1 | | | | | | |

**差距类型定义：**
- **功能缺失**：竞品有而我们完全没有
- **深度不足**：功能存在但深度差距大（如只有基础版，竞品有高级选项）
- **体验落后**：功能存在、深度接近，但交互细节差

## 四、报告写作要点
- **核心结论写在报告最前面**，不要让读者翻到最后才看到判断
- 每条结论必须有数据或截图支撑：
  - ❌ "搜索体验落后"（不是结论）
  - ✅ "搜索结果页无筛选条件，竞品 A 支持 5 种筛选维度，用户找到目标平均多花 40 秒"（才是结论）
- 建议具体到页面和功能模块，不出现"提升用户体验""优化交互流程"等无法执行的表述
