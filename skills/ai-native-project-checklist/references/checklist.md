# AI Native 项目启动 Checklist

> 每启动一个新项目，逐项对照打勾。勾完说明你已用 AI native 方式启动。

## 一、部署工作区

- [ ] 我已为这个项目新建了一个独立文件夹（在 Codex / Claude Code / WorkBuddy 等 Agent 中）
- [ ] 我对 AI 说的第一句话不是提需求，而是："我们准备在这个文件夹做 XX 项目，你先了解现有文件，思考还缺什么，先把工程框架搭起来"
- [ ] AI 已经帮我创建了目录结构（底层目录 + 二级目录），后续所有文件都放在这个文件夹里
- [ ] 如果项目已做了一半：我已把所有相关资料丢进文件夹，并告诉 AI"你是中途加入的，先向我提问，聊到你掌握足够上下文为止"
- [ ] 我没有打开一个新的对话框就开始问问题——那样 AI 每次都要重新认识我

**关键认知：** 文件夹的本质不是使用习惯，而是 AI native 的使用原则——从第一天起你和 AI 信息完全同频、持续协同。

## 二、喂养上下文

- [ ] 我已把项目相关的**私人资料**放进文件夹：会议纪要、聊天记录、邮件、过往方案、我的笔记
- [ ] 我已把**灰色地带信息**告诉 AI：用户心理、不成文的惯例、工作现场的微妙之处（而不是只给它"官方资料"）
- [ ] 我已创建或更新了 user.md / CLAUDE.md，里面写了我的背景、偏好、风格、做事原则
- [ ] 我已考虑：这个项目有哪些重要对话/灵感需要录音记录？录音工具已准备好（录音笔/手机/通义听悟）
- [ ] 我检查过：有没有 AI 读不了的文件格式？如果有，我已让 AI 自己想办法装插件或转换

**关键认知：** 比提示词更重要的是上下文（Context）。公共知识（收藏的文章）不值钱，私人知识（会议、感悟、闲聊）才稀缺。

## 三、沉淀 Skill

- [ ] 我已想清楚：这个项目中有哪些是我反复在做的事？（如：写方案、做调研、跟客户沟通、准备直播）
- [ ] 我已把至少 1 个高频任务梳理成了 SOP，写成 skill 让 AI 执行（而不是每次重新描述怎么干）
- [ ] 我的 skill 里写了我的个人偏好和风格，不是从别人那里下载来的通用模板
- [ ] 我已建立反馈闭环：AI 产出 → 我修改 → 告诉 AI"从我的修改中学习" → skill 更新

**关键认知：** Skill 是个人能力的外化和资产。别人的 skill 终究是别人的，你的 skill 带着你的味道。

## 四、让 AI 成为共创者

- [ ] 我已告诉 AI："你信息比我少，以后跟我交流先问我，不要急着回答"
- [ ] 我没有只让 AI"帮我写个东西"，而是问过它："你觉得我该做这个吗？有没有更好的方式？"
- [ ] 我已让 AI 主动思考过：基于现有资料，这个项目下一步应该做什么？有什么我没注意到的风险？
- [ ] 如果我有多个项目：我已考虑让 AI 跨项目理解我，而不是每个项目都是信息孤岛

**关键认知：** AI 不只是执行者，更是共创者。最高级的状态是 AI 帮你重新定义问题，而不只是帮你完成任务。警惕 AI 顺着你说——它不知道"工作现场"。

## 五、放大生命力

- [ ] 我已识别出：这个项目中哪些是重复性执行工作，可以交给 AI？
- [ ] 我已把省下来的时间安排给了"非执行"的事：见人、体验、阅读、深度对话、散步思考
- [ ] 我提醒自己：这些经历本身就是 AI 的语料，我活得越丰富，AI 帮我帮得越好

**关键认知：** AI 放大的不只是生产力，更是生命力。解放时间不是为了躺平，而是活得更充沛。

## 六、心法自检（项目过程中随时回看）

- [ ] 我在让 AI 帮我做事时，有没有先想清楚"我为什么要做这件事"？（而不是埋头执行）
- [ ] 我有没有过度依赖 AI 的答案，而放弃了自己的判断？（AI 会顺着你说，要警惕）
- [ ] 我的心力状态如何？AI 越强，我越要稳住自己的节奏和方向
- [ ] 我有没有回到"工作现场"思考？AI 不知道现场，我要主动把现场信息喂给它

**关键认知：** 修心 × AI = 人本主义超级个体。AI 是武器，你的心是瞄准器。武器越强，瞄准器越要稳。

---

## 优先级建议

如果时间有限，按以下顺序完成：

1. **部署工作区**（第一板块全部）——这是基础设施，必须最先做
2. **喂养上下文**（第二板块前 3 项）——私人资料、灰色地带、user.md
3. 其余板块可以在项目推进中逐步完善
