# 3D 验收指标模板

## 3D 指标设计方法

每个核心指标必须包含三个要素：

| 要素 | 含义 | 示例 |
|------|------|------|
| **Dimension（维度）** | 衡量什么 | 准确率、召回率、满意度、人工干预率、转化率 |
| **Degree（程度）** | 目标值 | 准确率 ≥ 92%、满意度 ≥ 85%、人工干预率 ≤ 10% |
| **Duration（周期）** | 达标时间 | 上线 3 个月内、灰度 2 周后 |

## 指标分类

### 效果指标（AI 输出质量）

| 指标 | 定义 | 目标值 | 周期 | 测量方式 |
|------|------|--------|------|---------|
| 准确率 | AI 输出正确的比例 | ≥ __% | | 评测集/人工标注 |
| 幻觉率 | AI 编造信息的比例 | ≤ __% | | 事实一致性检测 |
| 召回率 | 应返回结果中实际返回的比例 | ≥ __% | | 评测集对比 |
| 忠实度 | RAG 回答基于上下文的比例 | ≥ __% | | 回答与检索内容一致性 |
| 拒答率 | AI 拒绝回答的比例 | ≤ __% | | 日志统计 |

### 业务指标（商业价值）

| 指标 | 定义 | 目标值 | 周期 | 测量方式 |
|------|------|--------|------|---------|
| 转化率 | | ≥ __% | | 漏斗埋点 |
| 成本降低 | | 降低 __% | | 前后对比 |
| 收入增量 | | | | AB 测试 |
| 人工替代率 | AI 替代人工的比例 | ≥ __% | | 工单/任务统计 |

### 体验指标（用户感受）

| 指标 | 定义 | 目标值 | 周期 | 测量方式 |
|------|------|--------|------|---------|
| 采纳率 | 用户采纳 AI 输出的比例 | ≥ __% | | 采用/复制埋点 |
| 人工干预率 | AI 输出被修改的比例 | ≤ __% | | 修改行为埋点 |
| 任务完成率 | 用户成功完成目标任务的比例 | ≥ __% | | 任务埋点 |
| 响应时长 | P95 响应时间 | ≤ __ 秒 | 上线时 | 性能监控 |
| 满意度 | 用户主观评分 | ≥ __/5 | | 评分弹窗/问卷 |

## 指标设定注意事项

1. **目标值要有依据**：参考行业 benchmark、历史数据或竞品水平，不拍脑袋
2. **指标之间可能冲突**：如准确率 vs 覆盖率，需明确优先级
3. **护栏指标**：优化核心指标时监控护栏指标（如优化点击率时监控退货率）
4. **分阶段目标**：MVP 阶段目标可以低一些，随迭代逐步提升
5. **可测量性**：每个指标必须有明确的测量方式和数据来源，无法测量的指标不写
