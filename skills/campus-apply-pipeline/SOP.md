# 投递 SOP 总览（一页）

## 闭环全景

```text
[1] 读取候选人画像 (Obsidian / 简历 / 资料，信息源可配)
        │  提取：学校层级·专业·届别·实习·项目·技能·目标·个性化约束·排除清单
        ▼
[2] 岗位收集去重 ── 只认官方门户/官方 ATS（第三方仅作线索）
        ▼
[3] 登录官方门户 → 先查「投递记录 + 投递纪律(限投N岗)」
        ▼
[4] 找全非技术岗（AI 优先找全，也留非 AI）→ 多维评分、分梯队权重排序
        ▼
[5] 输出推荐列表(总分/小分/理由/风险提示) → ★用户第 1 次确认（选岗）
        ▼
[6] 在线简历按 JD 微调关键词 + 上传 PDF（先确认文件名/版本）
        ▼
[7] 提交前 ★用户第 2 次确认（公司+岗位）；滑块/验证码/扫码 → 交接用户
        ▼
[8] 投递记录页核验成功
        ├─► 回填飞书主表（复用线索行）→ P 键排序置顶 → 回读 → 交付
        └─► 双写妙搭看板「已投递」（备注=投递进度链接）
        ▼
[9] 下一家（回到 [2]）
```

## 逐家投递 Checklist

- [ ] 已读最新 `config/personal.md`（首次先从 `personal.example.md` 复制），简历版本确认
- [ ] 已重新拉取主表最新数据（未用旧行号）
- [ ] 已定位**官方门户**并登录（登录/扫码/验证码由用户完成）
- [ ] 已查「投递记录」：未重复、未超限投数
- [ ] 已找全产品/运营/管培/售前/解决方案岗（AI 优先）
- [ ] 已按 E/C/P/A 评分、按梯队权重排序
- [ ] 已把推荐列表发用户、拿到**选岗确认**
- [ ] 在线简历已按 JD 微调（不删经历、不编数据）
- [ ] 需传 PDF 的，已确认文件名/版本
- [ ] 提交前已**二次确认**；滑块等已由用户完成
- [ ] 投递记录页已核验（岗位/状态/时间）
- [ ] 主表已回填、P 键置顶、回读并交付
- [ ] 妙搭看板已双写「已投递」，备注为进度链接，用户本人可见

## 匹配评分速记

| 维度 | 看什么 | 大厂 | 中厂 | 小厂 |
|---|---|---|---|---|
| E 经历匹配 | JD 与实习/项目/技能重合 | .25 | **.50** | .30 |
| C 上岸机会 | 竞争反向：越易上分越高 | **.45** | .20 | .10 |
| P 背景&个性化 | 学校层级/届别/地点/薪资/出差 | .20 | .20 | .20 |
| A AI 相关度 | 是否 AI 产品/方案/运营 | .10 | .10 | **.40** |

各维 1–5 分，加权求总分降序。学历/专业/届别不符不否决，仅 ⚠ 提示（专业最不重要）。

## 状态流转（主表 M 列 / 看板 status）

```text
待投递 pending ──投递──► 已投递 applied
   已投递 ──► 笔试中 written_test ──► 面试中 interview ──► 已offer offer
   任一阶段未通过 ──► 已挂 failed
   挂因(O 列)：简历挂 / 笔试挂 / 面试挂
   （流程终止·初筛淘汰·综合评估不通过·暂不匹配·流程已结束 = 简历挂）
```

## 红线一句话

两次确认、只走官方门户、验证交用户、附件先确认、不编造、备注只放进度链接、写后必回读。
