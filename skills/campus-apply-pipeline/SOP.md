## 逐家投递 Checklist

- [ ] 已读最新 `config/personal.md`（首次先从 `personal.example.md` 复制），简历版本确认
- [ ] 已重新拉取主表最新数据（未用旧行号）
- [ ] 已定位**官方门户**并登录（登录/扫码/验证码由用户完成）
- [ ] 已查「投递记录」：未重复、未超限投数
- [ ] 已找全产品/运营/管培/售前/解决方案岗（AI 优先）
- [ ] 已按 E/C/P/A 评分、按梯队权重排序
- [ ] 已把推荐列表发用户、拿到**第 1 次确认（选岗）**
- [ ] 已调用简历 skill `resume-jd-align`，且**只改在线简历**
- [ ] JD 关键词已按 ATS 提取，并自然融入「经历证据 bullet」（未堆个人评价、未改四字小标题）
- [ ] 事实/数据/成果零改动，经历顺序与独立项目未删减；附件 PDF 未定制
- [ ] 已展示改动明细、拿到**第 2 次确认（保存在线简历前）**后才点保存
- [ ] 需传 PDF 的，已确认文件名/版本
- [ ] 提交前已报公司+岗位、拿到**第 3 次确认（提交投递）**；滑块等已由用户完成
- [ ] 投递记录页已核验（岗位/状态/时间）
- [ ] 主表已回填、P 键置顶、回读并交付
- [ ] 妙搭看板已双写「已投递」，备注为进度链接，用户本人可见

## 匹配评分速记

| 维度 | 看什么 | 大厂 | 中厂 | 小厂 |
|---|---|---|---|---|
| E 经历匹配 | JD 与实习/项目/技能重合 | .25 | **.50** | .30 |
| C 上岸机会 | 竞争反向：越易上分越高 | **.45** | .20 | .10 |
| P 背景&个性化 | 学校层级/届别/地点/薪资/出差 | .20 | .20 | .20 |
| A AI 相关度 | 是否 AI 产品/方案/运营 | .10 | .10 | **.40** |

各维 1–5 分，加权求总分降序。学历/专业/届别不符不否决，仅 ⚠ 提示（专业最不重要）。

## 在线简历微调口径（第 6–7 步）

- 必须调用简历 skill `resume-jd-align`；**只改在线简历**，附件 PDF 统一通用版。
- 先按 ATS 读完整 JD，提取硬技能 / 业务场景 / 软素质三类关键词。
- 关键词**自然融入对应经历的「证据 bullet」**（职责/方案/成果描述行），与事实贴合、不堆砌。
- **不**把关键词写进个人评价/自我评价；**不**改长或改名【】四字小标题（保持恰好四个汉字）。
- 保存前展示改动明细并取得第 2 次确认。

## 状态流转（主表 M 列 / 看板 status）

```text
待投递 pending ──投递──► 已投递 applied
   已投递 ──► 笔试中 written_test ──► 面试中 interview ──► 已offer offer
   任一阶段未通过 ──► 已挂 failed
   挂因(O 列)：简历挂 / 笔试挂 / 面试挂
   （流程终止·初筛淘汰·综合评估不通过·暂不匹配·流程已结束 = 简历挂）
```

## 红线一句话

三次确认（选岗/保存简历/提交投递）、微调必调简历 skill 且只改在线简历、关键词融入证据不堆评价不改小标题、只走官方门户、验证交用户、附件先确认、不编造、备注只放进度链接、写后必回读。
