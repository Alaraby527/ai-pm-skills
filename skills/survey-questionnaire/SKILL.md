# 调研问卷设计 Skill

## 简介

**干什么的**：用户研究问卷设计与数据分析方法论工具包。从调研目标到问卷题目设计、信效度保障、交叉分析框架，输出完整问卷与分析方案。

**核心方法论**：6 步问卷设计工作流 + 题目设计原则与题型选择指南 + 信效度保障方法 + 交叉分析框架（描述统计→交叉分析→相关性分析→洞察提炼）。

**你能得到什么**：完整调研问卷、问卷设计优化建议、问卷数据分析报告（含交叉分析）、用户分层结果、调研结论与建议。

**文件结构**：
```

├── SKILL.md                              # 主文档：触发条件 + 工作流 + 质量红线
└── references/
    ├── template-questionnaire.md          # 问卷设计完整模板

    ├── prompts.md                         # 各阶段提示词合集

```

## 触发场景

当用户需要设计问卷或分析问卷数据时触发。典型场景包括：
- 设计用户满意度/产品使用调研问卷
- 设计市场调研问卷
- 问卷题目设计与优化
- 问卷数据分析与交叉分析
- 写问卷调研报告

> **与 `data-analysis` 的边界**：问卷回收数据的分析在本 skill；业务大盘、漏斗、AB 实验、AI 质量日志等行为数据分析去 `data-analysis`。

## 输入要求

**必需信息**：
- 调研目标（为什么做问卷）
- 待验证的假设（或要回答的问题）
- 目标用户群体

**可选补充信息**：
- 样本量预估
- 发放渠道
- 已有假设/前期调研发现

**信息不全时的追问话术**：
- 缺调研目标："这份问卷主要想回答什么问题？比如是了解用户满意度、验证某个需求，还是为产品迭代找方向？"
- 缺目标用户："问卷发给谁？是现有用户、潜在用户，还是特定人群？"
- 缺假设："你有哪些想验证的假设？我会围绕假设设计题目，避免问卷变成'什么都问但什么都没回答'。"

## 工作流（6 步）

### Step 1：明确调研目标与假设

- 明确问卷要回答的核心问题（3-5 个）
- 列出研究假设（每个假设可被数据验证或证伪）
- 确定需要收集的数据类型（行为数据/态度数据/人口统计）
- 确定输出物形式和颗粒度

**检查点**：动笔设计题目前，向用户复述 3-5 个核心问题与假设清单，确认后再进入问卷结构设计。

### Step 2：设计问卷整体结构

标准结构：
1. **甄别题**（2-3题）：筛选目标用户，不符合的直接结束
2. **人口统计题**（3-5题）：性别、年龄、职业、城市等（按需）
3. **核心行为题**（5-10题）：使用频率、使用场景、功能使用等
4. **态度题**（5-10题）：满意度、NPS、态度量表等
5. **开放题**（1-2题）：收集未覆盖的意见和建议

> 问卷总时长控制在 5-10 分钟（约 20-30 题），太长会降低完成率

### Step 3：编写具体题目

**题目设计原则**：
- 避免双重含义（一个问题只问一件事）
- 避免引导性/倾向性措辞
- 选项互斥且穷尽
- 量表一致性（统一用 5 点或 7 点 Likert）
- 敏感问题后置
- 按逻辑顺序排列（从易到难、从行为到态度）

**常见题型选择指南**：
| 要测什么 | 推荐题型 |
|---------|---------|
| 使用频率/时长 | 单选题（选项分段） |
| 满意度 | Likert 量表（5点/7点） |
| 忠诚度 | NPS（0-10分） |
| 功能重要性 | 重要-满意度矩阵题 |
| 多选问题 | 多选题（注意选项不重叠） |
| 开放意见 | 开放题（1-2道足够） |

### Step 4：预测试与优化

- 找 5-10 个目标用户做预测试
- 检查：题目是否理解一致？有没有歧义？有没有答不出来的？
- 检查完成时长（超时要删题）
- 修改后定稿

### Step 5：发放与数据回收

- 选择发放渠道（问卷平台 / 产品内弹窗 / 社群 / 邮件）
- 设置质量控制（答题时间过短的标记为无效）
- 监控回收进度和样本构成
- 目标样本量参考：
  - 描述性研究：至少 100 份
  - 对比分析：每组至少 30 份
  - 因子分析/聚类分析：至少 200 份

### Step 6：数据分析与报告输出

**分析框架**：
1. **描述统计**：各题的分布、均值、占比
2. **交叉分析**：
   - 用户分层 × 满意度（不同人群满意度差异）
   - 使用行为 × 态度（高频用户和低频用户的态度差异）
   - 人口统计 × 行为（不同年龄/性别的使用差异）
3. **相关性分析**：哪些因素和满意度/NPS 最相关
4. **洞察提炼**：从数据到结论到建议

## 质量红线

1. **问卷必须围绕调研目标设计**，每道题都要能对应到一个研究问题或假设，不允许"随便问问"的题目。
2. **题目表述必须中立**，不允许引导性措辞（如"你不觉得 XX 功能很好用吗？"）。
3. **选项必须互斥且穷尽**，不允许选项重叠或遗漏重要选项（"其他"除外）。
4. **问卷长度控制在 20-30 题/5-10 分钟**，超过必须删减。
5. **数据分析不得编造数据**：没有回收数据时只输出问卷和分析方案，不虚构分析结果。
6. **结论必须有数据支撑**：每个结论标注样本量和比例，不允许"大部分用户认为…"而不给数字。
7. **相关不等于因果**：交叉分析发现相关性时，不得直接推断因果关系。

## 异常兜底

| 异常情况 | 处理方式 |
|---------|---------|
| 用户没有数据，只要问卷 | 输出完整问卷 + 数据分析方案（含交叉分析计划），说明回收数据后可继续分析 |
| 样本量不足（< 100） | 只做描述性统计，不做推断统计，标注"样本量有限，结论仅供参考" |
| 数据质量差（大量无效问卷） | 先做数据清洗（剔除答题时间过短、直线作答等），报告有效样本量和清洗规则 |
| 用户要求问卷"什么都问" | 帮用户聚焦到 3-5 个核心问题，说明问卷过长会降低完成率和数据质量 |
| 敏感问题（收入等）拒答率高 | 提供区间选项而非精确数字，或标注"选填"，分析时说明缺失情况 |
