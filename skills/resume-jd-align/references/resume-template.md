# 简历优化模板

## 标准简历结构

```
┌─────────────────────────────────┐
│ 姓名 | 电话 | 邮箱 | 求职意向     │  ← 个人信息（3 项必备）
├─────────────────────────────────┤
│ 教育经历（倒序）                  │
│ 时间 | 学校 | 专业 | 学历         │
├─────────────────────────────────┤
│ 工作经历                         │
│ 公司 | 职位 | 时间               │
│ 公司简介（1 句）                 │
│ 核心工作 + 量化成果（3-5 条）     │
├─────────────────────────────────┤
│ 项目经历（2-4 个高匹配项目）      │
│ 用万能项目描述公式               │
├─────────────────────────────────┤
│ 自我评价（2-3 行，可选）          │
└─────────────────────────────────┘
```

## 万能项目描述公式

```
【项目标题】一句话说清项目是什么

背景：业务痛点 + 用户未被满足的需求 + 商业价值（1-2 句）
方案：
- 策略/功能 1：设计逻辑 + 对应需求
- 策略/功能 2：设计逻辑 + 对应需求
- 策略/功能 3：设计逻辑 + 对应需求
亮点：创新点 / 难点突破 / 跨部门推动（1-2 条）
结果：核心指标从 X 提升到 Y（必须量化）
复盘：1 句话产品认知升级
```

## 简历自查清单

- [ ] 页数：5 年以下 1 页，5 年以上不超过 2 页
- [ ] 无错别字、格式统一
- [ ] 每个项目都有数据结果
- [ ] 自我评价每句话都有项目论据
- [ ] JD 关键词命中率 ≥ 70%
- [ ] 没有"负责""参与"等无价值动词开头
- [ ] 没有空泛形容词（"逻辑强""沟通好"）
- [ ] 项目按与 JD 匹配度排序，不按时间排序
