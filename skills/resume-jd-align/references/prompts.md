# 简历-JD 对齐提示词合集

## 1. JD 关键词提取

```
请分析以下 JD，提取三类关键词并按重要性排序：

【JD 内容】
{jd_text}

请按以下格式输出：
1. 硬技能关键词（必须命中）：
2. 业务场景关键词（优先命中）：
3. 软素质关键词（加分项）：

对每个关键词标注：JD 中的原文表述、权重（高/中/低）。
```

## 2. 简历结构体检

```
请以 HR 视角审查以下简历，按五大致命错误逐项检查：

【简历内容】
{resume_text}

检查项：
1. 基础排版（错别字、字体、页数）
2. 结构清晰度（模块划分、信息层级）
3. 自我评价是否有效（有无空泛表述）
4. 项目描述是否泛化（是职责描述还是成果描述）
5. 数据支撑（有无量化结果）

每项给出：问题描述 + 修改建议。
```

## 3. 项目描述改写

```
请用万能项目描述公式改写以下项目经历：

公式：项目标题 + 背景 + 方案 + 核心亮点 + 数据结果 + 复盘认知

【原始描述】
{project_text}

要求：
- 背景：业务痛点 + 用户需求 + 商业价值（1-2 句）
- 方案：分点列出，每条对应一个明确需求
- 亮点：突出创新点和难点突破
- 结果：必须量化，没有数据请标注【需补充数据】
- 复盘：1 句话产品认知升级
- 总长度控制在 150-250 字
```

## 4. 自我评价精炼

```
请将以下自我评价改写为 2-3 行精炼版本：

【原始自我评价】
{evaluation_text}

【项目经历摘要】
{project_summary}

要求：
- 第一段：从业年限 + 深耕赛道 + 核心操盘模块
- 第二段：差异化亮点（大厂背书/从0到1/核心增长成果）
- 每句话必须能在项目经历中找到论据
- 拒绝空泛形容词（"逻辑强""沟通好"无佐证一律删除）
```

## 5. 三梯队岗位盘点

```
请根据以下信息帮我规划三梯队岗位表：

【求职诉求】
{job_goals}

【当前背景】
{background}

请输出：
1. 第一梯队（冲刺岗）：5-8 个目标公司/岗位类型，说明匹配理由
2. 第二梯队（主力岗）：15-20 个，说明匹配维度
3. 第三梯队（试水岗）：10-15 个，说明练手价值
4. 三阶段投递节奏建议
```
