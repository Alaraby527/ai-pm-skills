# 七类题库的展开模板

Step 5 按此为每一类写出可直接念的答案。括号内是该类题的考察意图。

## 1. 经历深挖（考察：项目是真做过还是背的）

标准答案结构 = 四要素齐全版：
- 背景（两句）
- 问题（别人为什么没解决）
- 过程（我的判断 → 具体动作 → 为什么这么选）
- 结果（量化 + 对比基线）

承接句：「如果您想了解其中某一步，我可以展开讲。」

## 2. 简历细节（考察：简历有没有注水）

规则：简历上**每一个数字、每一个名词**都要能展开讲 2 分钟。写不出来就删掉那行。

自查方式：拿荧光笔划简历上所有量化数字和专有名词，逐个问自己"这个数是哪来的？口径是什么？"

## 3. 事件层与动作层（考察：是不是真的参与）

很多人被问"你具体做了什么"时，开始重复"我们做了什么"。必须能分开答：

- **事件层**：这个项目做成了什么（团队视角，讲结果）
- **动作层**：我负责的是哪一个模块、我亲手交付了什么、我的决策边界在哪

## 4. 经历追问（考察：复盘能力）

三类必问题：**失败经历 / 被否掉的方案 / 和同事的冲突**。

答案四件套：当时的判断 → 错在哪 → 事后怎么补 → 沉淀了什么可复用的东西。
⛔ 忌讳：把失败讲成"因为我太拼了"；把冲突讲成对方全错。

## 5. 职业规划与岗位认知（考察：稳定性与动机）

- 三年短期 + 长期方向，**且要能和目标岗位对上**（不是背成长计划，是要说明这个岗位在你规划里的位置）
- 为什么选这个岗位：必须具体到某个业务判断，禁止"平台大/氛围好/技术强"

## 6. 行业与公司认知（考察：是不是海投）

必须包含三类信息（**不得凭印象，须真实检索**）：
1. 公司最近的真实动态（产品动作、财报口径、发布会）
2. 竞品同期在做什么
3. 你的判断与疑问

高分句式：「我注意到贵司 X 月做了 ___，而竞品 ___ 选择了另一条路，我理解差异在于 ___，但也意味着 ___ 风险。」

> 长期习惯：目标公司及竞品的近期动作要持续输入，这不是押题，是证明你在认真研究这个平台。

## 7. 方案题（考察：结构化思维）

固定链路，不得直接跳答案：
1. **拆解**：把模糊目标拆成可判断的子问题
2. **假设**：给出优先级最高的假设与理由
3. **验证**：用最小成本怎么验证（数据/实验/用户访谈）
4. **指标**：先看什么指标，多久算验证成功

⛔ 忌讳：一上来给功能列表；不考虑资源和阶段。

## 附加：商业思维与逻辑表达的日常修炼

- 搞懂目标公司的商业模式；找同类案例做对比
- 掌握总分总表达框架
- 学会提问（能不能提出好问题，本身就是面试官在观察的能力）
