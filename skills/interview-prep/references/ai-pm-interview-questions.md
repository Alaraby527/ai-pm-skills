# AI PM 专项面试题

## 一、AI 技术认知

### Q1：AI 应用开发和底层模型开发有什么区别？市场占比如何？
**答题要点**：
- 底层模型：算力密集、数据密集、人才密集，少数玩家（OpenAI/Anthropic/字节/百度等）
- 应用层：场景理解、产品设计、用户体验，大量机会
- 市场占比：应用层市场规模远大于模型层（参考：模型层约 10-20%，应用层约 80-90%）
- AI PM 的价值在应用层：把模型能力转化为用户价值

### Q2：为什么不能只调用外部 API？
**答题要点**：
- 数据安全：核心业务数据不能出域
- 业务定制：通用 API 无法满足垂直场景的精度要求
- 成本控制：高频调用下 API 成本可能高于自研
- 差异化竞争力：只调 API 没有护城河
- 但也要分阶段：MVP 阶段可以先用 API 验证，再逐步自研

### Q3：RAG、微调、Prompt 工程分别适用于什么场景？
**答题要点**：
| 方案 | 适用场景 | 成本 | 周期 |
|------|---------|------|------|
| Prompt 工程 | 通用任务、快速验证 | 低 | 天级 |
| RAG | 需要私有/实时知识、答案可溯源 | 中 | 周级 |
| 微调 | 特定风格/格式/领域深度适配 | 高 | 月级 |

## 二、AI 产品设计

### Q4：如何评估一个 AI 功能是否可行？
**答题要点**：四维可行性评估
- 技术可行性：模型能力是否支撑
- 数据可行性：数据从哪来、够不够
- 成本可行性：开发+运行+维护成本 vs 收益
- 合规可行性：数据隐私、内容安全

### Q5：AI 产品和传统产品最大的区别是什么？
**答题要点**：
- 输出不确定性：同一输入可能有不同输出，需要兜底
- 评估维度不同：除了业务指标，还要评估 AI 质量指标（准确率/幻觉率/采纳率）
- 交互模式不同：对话式/生成式 vs 表单/按钮
- 迭代方式不同：Bad Case 驱动迭代，需要灰度+监控+反馈闭环

### Q6：AI 答错了怎么办？
**答题要点**：
- 预防：置信度阈值、敏感场景人工审核
- 兜底：转人工、给出降级方案、提示用户核实
- 反馈：用户纠错入口、Bad Case 收集
- 迭代：归因→优化→回归测试

## 三、AI 项目落地

### Q7：AI 项目的成本怎么估算？
**答题要点**：
- 开发成本：人力（算法+工程+产品）、时间
- 运行成本：Token 费用/算力费用（按调用量估算）
- 维护成本：数据更新、模型重训练、Bad Case 优化
- ROI：成本节省 or 收入增量 vs 总成本

### Q8：如何设计 AI 产品的验收指标？
**答题要点**：3D 指标
- Dimension（维度）：效果/业务/体验
- Degree（目标值）：基于 benchmark 设定
- Duration（周期）：分阶段达标
