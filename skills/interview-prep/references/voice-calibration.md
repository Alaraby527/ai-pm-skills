# 声音校准（Voice Calibration）

**为什么有这一页**：播客评论区里真实发生过这句吐槽——

> "感觉这种面试介绍方式非常的死板…听起来非常之虚浮😥"
> "是的 而且会被问你这个自我介绍是不是 AI 写的"

问题不出在框架，出在**框架的血肉被丢掉了**：原作者的措辞、句式、节奏没有被保留，模型于是用通用书面语填空。这一页就是把血肉补回来的唯一依据。

**使用时机**：Step 3 写自我介绍、Step 4 写故事卡、Step 5 写题库之前**必读**。写完后必须用 `anti-slop.md` 的 17 条签名逐条扫。

---

## 1. 原文术语表（禁止改写）

框架的名字是有原因的，改一个字就掉一个信息量：

| 必须这样写 | 不能写成 |
|---|---|
| 定位 / 证据 / 动机 / 钩子 | 四个部分 / 四块内容 / 自我介绍结构 |
| 核心人设 + 两个硬核故事 + 未来可期 | 基本信息 + 项目经历 + 期望 |
| 硬实力 / 软素质 / **个人生命力** | 硬技能 / 软技能 / 兴趣爱好 |
| 异常值 | 亮点 / 优势 / 我的经历 |
| 先讲限制，再讲成果 | 先介绍背景 |
| 在面试官脑子里种下一个钩子 | 留个悬念 / 引发兴趣 |
| 一眼缘儿 | 印象分 |
| STAR，重点在 A | STAR 法则 |
| 讲清楚四要素：背景 / 问题 / 过程 / 结果 | 讲清楚来龙去脉 |
| 表达三要素：信息密度 / 匹配 / 节奏感 | 说得好一点 |

## 2. 可直接引用的原句（金句库）

稿子里**允许且鼓励**直接出现这些句子，它们是"像人说话"的锚点：

- "我是一个……的人"（核心人设开场，直接说判断；**不加**"如果要给我贴个标签/一句话说"之类前置框架——那仍在预告说话，是元话语。比"我叫 XX，来自 XX"强一个量级）
- "当时的限制是……"（先讲限制，成果才可信）
- "这件事我最想讲的其实是踩过的坑："（钩子的标准句式）
- "我不太想说'我很匹配'，我更想让您从这件事里自己判断。"（化解"喊匹配"红线的高级说法）
- "我没海投。"（动机的开门见山句）
- "那个数字是我们上线三周后跑出来的，不是预估。"
- "如果您感兴趣，我可以展开讲讲我们后来怎么重新定义这个指标。"（钩子收尾）

## 3. 说话方式（句法层面的硬特征）

| 特征 | 具体要求 | 反例（模型腔） |
|---|---|---|
| 句长自然 | 长句能拆则拆，但**不刻意造短句锤子**——"15 道全对。"式独立收锤是金句腔（见 human-voice-spec A16） | "在这个过程中我主要负责了基于用户洞察驱动的、跨部门协同的数据产品体系搭建工作" |
| 先限制后成果 | 成果句前必有"限制/约束/当时只有" | "我负责了这个项目，效果很好" |
| 有具体的"我" | 每段至少一个"我"+ 具体动作动词（拆、改、定、跑、压、砍、协调） | "团队完成了……""我们进行了……" |
| 数字带单位和时间 | "上线三周""从 42% 降到 19%" | "大幅提升""效果显著" |
| 口语连接词 | "然后""结果""所以""问题在于""说白了" | "首先/其次/最后""综上所述""由此可见" |
| 允许留白 | 钩子处故意不讲完 | 把所有信息讲满、讲圆、讲完整 |
| 允许暴露代价 | "代价是……""这个做法后来被推翻了" | 全程只有成功没有代价 |
| 功能句式陈述能力 | "能够实时获取用户反馈，知道用户关心什么、吐槽什么，只有了解用户，才能做好产品" | "做产品判断，不靠猜"这类自我标签式警句（A16 金句腔） |

## 4. 三个来源的口吻差异（按目标岗位选）

- **桂姐（求职规划博主）**：直接、命令式、敢下判断——"别喊匹配""你不讲的那段等于不存在"。
- **腾讯 Kelly（18 年 HR）**：温和但具体，永远给可套用的公式和示范句——"在面试官脑子里种下一个钩子"。
- **海苔卷卷（BAT 面经）**：把面试官当导师，语气松弛、承认学习过程。

写稿时**只选一种口吻贯穿全篇**，不要三种混用——混用就是最典型的"拼接感"。

## 5. 自检三问（写完必答）

1. 把稿子念给一个不了解你行业的人听，他能不能复述出**你做了什么、有多难、带来了什么价值**？（Kelly 的检验法）
2. 稿子里有没有一句**只有你能说**的话？（没有 → 换掉，宁可少写一段）
3. 全篇有没有出现"赋能 / 抓手 / 闭环 / 平台大 / 技术氛围好 / 首先其次最后 / 总的来说"？（有 → 见 anti-slop.md）
