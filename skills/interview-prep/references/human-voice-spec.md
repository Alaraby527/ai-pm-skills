# AI 味判定与拟人化规范（Human Voice Spec）

**为什么有这一页**：框架对了、禁词也扫过了，产出仍然"非常死板、AI 感很重"——典型症状是自我介绍被拆成几个点、像分点答题、不像一段完整的话。原因不在词汇，在**形状**：模型把生成用的结构骨架直接外显成了输出格式。这一页把"AI 味"拆成可判定的具体特征，把"像人说话"拆成可执行的正向规则。

**一句话定义**：AI 味 = 写作的形状泄露到了说话的场合。人说话没有目录、没有序号、没有小标题；一旦稿子有这些，内容再真也像 AI。

**使用时机**：写任何成稿**之前**，先通读 `references/examples.md` 的「版本三 · 合格稿」——**示例先于规则**：模仿一篇好例子的节奏，远比遵守十条规则可靠。然后回本页 §1 §2 §3 查规则定稿；成稿之后按 §8 自检。`scripts/lint_intro.py` 已内置 §1 中标"脚本"的特征判据（扫描「开讲版」区域）。

## §1 什么是 AI 味：16 个具体特征（A1–A16）

### A1 结构外显（最典型，最致命）
- **症状**：稿子被拆成几个点。序号（1. 2. / ①②③ / 第一，第二，）、列表符号（- / •）、小标题、加粗、【标签】、「背景：/问题：/过程：/结果：」式字段冒号、markdown 标题，任何一种出现在成稿里。
- **坏例**：
  > 1. 专业能力：具备扎实的数据分析与产品思维能力
  > 2. 项目经历：曾在某公司实习，参与 AI 客服产品优化项目
  > 3. 求职动机：非常认可贵司的技术氛围与发展平台
- **为什么假**：人不会在口语里给自己的话编目录。分点等于告诉面试官"我在背一份提纲"。
- **判据**（脚本）：成稿区域出现行首序号/列表符/【】/字段冒号/加粗/标题 → ❌。**分点只允许出现在工作台区（素材整理），成稿区零容忍。**

### A2 元框架（预告和总结自己要说的话）
- **症状**："接下来我将从三个方面介绍自己""下面我简单介绍一下""刚才我讲了我的……现在再讲……"。
- **坏例**：`接下来我将从三个方面介绍自己`
- **为什么假**：这是在描述说话这个行为，而不是说话本身。人直接说事，不报流程。
- **判据**（脚本 S1）：开头 200 字内出现"接下来我将/我将从…方面/从以下几个方面" → ❌。

### A3 收尾腔
- **症状**："总的来说/综上所述/以上就是我的自我介绍/希望有机会加入贵司/谢谢聆听"。
- **为什么假**：模型收尾的默认姿势。真候选人结尾落在内容上（一个钩子），不落在礼仪上。
- **判据**（脚本 S6）：命中任一 → ❌。**正确收尾：钩子半句。**

### A4 排比与等长句阵
- **症状**："既…又…更…"三连；每个分句长度几乎一样；对仗工整的三个短语并列（"有热情、有能力、有担当"）。
- **为什么假**：即兴口语做不到工整对仗。工整 = 写的，且是为"显得有气势"而写，不是为了说清楚。
- **判据**：≥3 个等长（±3 字）分句并列 → 人工判定。

### A5 形容词垫场
- **症状**：事实还没出场，形容词先铺一排——扎实/丰富/良好/深入/较强/全面/显著。
- **坏例**：`我具备扎实的数据分析能力和丰富的项目经验`
- **为什么假**：人在陈述事实时不需要给自己打分；先给结论后给形容词是"证明文"的写法，不是叙事。
- **判据**：形容词出现处往后 30 字内没有数字或具体事件 → 删形容词。

### A6 名词化 + 弱动词
- **症状**："进行了…的优化""实现了…的提升""完成了…的搭建"——动词被抽掉，只剩名词壳。
- **坏例**：`对客服流程进行了系统性的优化，实现了效率的显著提升`
- **改法**：`我把客服流程里的三步人工核验砍成一步，回复时间从四小时压到一小时`
- **判据**（脚本 S3）：名词化结构 > 3 处/100 字 → ❌。

### A7 黑话密度
- **症状**：赋能/抓手/闭环/打法/颗粒度/对齐/沉淀/心智/护城河/底层逻辑。
- **为什么假**：黑话是回避具体的手段。每个黑话翻译过来都是一句要费力写的事实，用词代替事实就露馅。
- **判据**（脚本 S9）：单篇 ≥3 个 → ❌；口语稿里"底层逻辑"最多出现 1 次。

### A8 完美平滑
- **症状**：全篇只有成功：没有限制、没有代价、没有犹豫、没有走错的方向。什么都"顺利完成""成功实现"。
- **为什么假**：真事都有毛边。没有代价的成果不可信（方法论本身要求"先讲限制，再讲成果"）。
- **判据**（脚本 S10）：全篇无限制/代价/失败词 → ❌。**至少一处"当时的限制是…"，至少一处代价或走弯路。**

### A9 泛指代替专名
- **症状**：某公司/一家公司/一个项目/相关工作/多次/大量/若干。
- **为什么假**：真实记忆自带专名和数字（"在瑞幸小程序那会儿"）；泛指是生成时没有事实可用的标志。
- **判据**（脚本 S4）：命中泛指短语 → ⚠️ 必须补专名或数字。确实不能透露的名字用可核实的口径替代（"一家做电商 SaaS 的公司，二十人规模"）。

### A10 情绪扁平
- **症状**：全文没有一处语气起伏——没有口语标记（其实/当时/后来/结果/说白了/挺…的），没有叙事时间词（那时候/上线前一周/实习第二个月），像新闻通稿。
- **为什么假**：人在讲自己的经历时自带时间线和情绪；扁平 = 没经历过，是在概述别人的事。
- **判据**（脚本，正向检查）：叙事时间标记 ≥1、口语标记 ≥1，缺失 → ⚠️。

### A11 节奏均匀（念稿感）
- **症状**：每句话 15–25 字，句句结构相似，没有短句落锤，没有停顿。读起来像播报。
- **坏例**（连读感受）：每句都长、都带两个逗号、都以逗号收尾再接下一句。
- **为什么假**：即兴表达的长短是跟着思维走的——铺陈时长，下结论时短。"最后排队基本没了"比"最终有效解决了排队问题"像人得多。
- **判据**（脚本 S12）：≥6 句且没有任何 ≤10 字短句 → ❌；单句逗号 ≥4 → 拆句。

### A12 总结态代替叙事态
- **症状**："在任期间/工作过程中/项目周期内，我负责…"——用 HR 档案腔概述自己，而不是回忆某段具体时间发生的事。
- **坏例**：`实习期间，我主要负责需求分析与跨部门协同工作`
- **改法**：`实习第二个月，组里要上线 FAQ 检索，需求评审吵了三轮，我把三方拉齐定了一个口径`
- **为什么假**：同一个经历，叙事态（有当时、有场景、有动作）才携带"我在场"的证据；总结态只是标签。
- **判据**：故事段内无"当时/那/先…再…"等在场标记 → 人工判定。

### A13 编导式转场（结构播报）
- **症状**：段落衔接处出现"精悍对仗"的结构预告句——`这个数怎么来的，就说这段。` `轮到交互。` `话说到这。` `从头讲。` 它们不推进内容，只播报"我要开始说下一段了"。
- **为什么假**：真人转场要么带信息（时间/因果/话题），要么干脆不转、直接说下一件事。真实语料里零结构播报；且转场越"精悍"（每字都在干活、对仗工整），编导痕迹越重。真人衔接词反而是松的、有冗余的（然后/后来/就是/这块）——**"字字有用"本身就是写稿的证据**。
- **坏例 vs 好例**（同一位置）：
  - ❌ `这个数怎么来的，就说这段。`（纯结构胶水，4+4 对仗）
  - ❌ `那三个月我没先碰模型。`（刻意悬念桥，见 A15——不携带信息，删掉后故事照样完整）
  - ✅ 直接删，下一句以事实开场：`接手的时候，商品信息匹配准确率只有 78%。`（手段→成果，平铺直叙）
- **判据**（人工，脚本 S13 兜底）：**删掉这句转场，前后内容能否直接相连？能 = 纯结构胶水 → 删掉，或换成带时间/因果/话题信息的转场（见 H1 词库）。**

### A14 术语泄漏（工作台词汇进了成稿）
- **症状**：准备过程的自造词/行话直接出现在成稿里——`最硬的一个数` `最硬的一段` `深水区` `弹药` `埋钩子` `贴标签` `北极星指标`。
- **坏例 vs 好例**（同一位置）：
  - ❌ `最硬的一个数，是在导购 Agent 项目把转化率做到 26%。`
  - ✅ `我有四段 AI 相关的实习，其中最核心的一段是在一家电商大厂做 C 端导购 Agent，主要负责知识库、提示词和评测的迭代，咨询下单转化率从 18% 做到了 26%。`
- **为什么假**：面试官没读过你的方法论。这些词是**给准备过程用的**，出现在口语里等于自曝"我在执行一套方法"；而且"最硬的一个数"这种自造压缩语，正常人聊天不会说。真人报经历就是朴素的："最核心的一段是在 X 做 Y，主要负责 Z。"
- **判据**（人工，脚本 S14 兜底）：成稿里每个名词，面试官凭常识能懂吗？来自你工作台而非行业通用语的（最硬的/深水区/弹药/钩子）→ 换成面试官视角的自然说法。

### A15 刻意修辞桥（悬念句 / 反转句 / 设计回指）
- **症状**：为戏剧效果而非为信息服务的句子——
  - 悬念式 withhold-reveal：`那三个月我没先碰模型。` `这 37.5% 不是调模型调出来的。`（先按住不说，制造"其实我做的是 X"的揭晓感）
  - 设计回指收束：`我开头那句话，就是这么来的。`（为了首尾呼应而呼应）
- **为什么假**：这是写文案的修辞手法，面试口语里报经历就是朴素的**手段→成果**：做了什么，结果如何。修辞句一出现，面试官听到的不是经历，是"稿"。
- **判据**（人工，脚本 S15 兜底）：这句话删掉后，故事的信息有损失吗？没有损失、只剩"效果"的 → 删。（"我没先碰模型"想表达的侧重，由你接下来先讲什么自然体现，不用预告。）

### A16 金句腔（自我标签式警句 / mic-drop 收锤）
- **症状**：把能力或结果压缩成对仗短句、口号或独立收锤句——`做产品判断，不靠猜` `没换模型，只调了分块。15 道全对。` `把方法做成工具这件事，我一直在做` `模型一个字没换。`
- **为什么假**：这是广告文案和自媒体的收束技巧，念出来像在给自己写 slogan。真人陈述能力用平实的功能句，用具体对象落地，不做自我评价式的漂亮收拍。
- **改法（对照）**：
  - ❌ `长期泡在 AI 用户堆里——做产品判断，不靠猜。`
  - ✅ `独立运营 200 多人的社群，长期泡在 AI 创作者和重度用户堆里，能够实时获取用户反馈，知道用户关心什么、吐槽什么，只有了解用户，才能做好产品。`
  - 形态差异：✅ 句用**功能句式**（能够 X / 知道 Y / 这也算 Z 的一次验证）和**常理逻辑句**收尾（只有…才…，说的是事理，不是夸自己）；❌ 句是自我标签式警句。
- **判据**：这句话是在"陈述事实和能力"，还是在"给自己写 slogan"？数字结果不单独成句当锤子（`15 道全对。` → `调整之后 15 道全部通过`）。

## §2 什么是像人说话：14 条正向规则（H1–H14）

拟人不是加语气词那么简单——是在**形状、节奏、视角、颗粒度**四个层面同时像人。前 3 条是最高优先级。

### H1 一口气成文（形状）
- **规则**：开讲版 = 一到两段连续的话。转场用真实口语的四类衔接，**永不播报结构**：
  1. **时间链**（最常用）：后来 / 那阵子 / 毕业后 / 工作 X 年后 / 实习那三个月 / 再往后 / 最近
  2. **因果链**：因为想 X，我 Y / 为了 X 我做了 Y / 所以我离开了
  3. **话题链**：另外（一段）/ 还有一段 / X 这块 / 对了
  4. **回指**：开头那句话就是这么来的 / 先查链路这四个字 / 就是刚才说的那件事
  5. **经历引入**（报经历的标准句式）：`我有 N 段 X 相关的实习，其中最核心的一段是在 X 做 Y，主要负责 Z`——先报组合再聚焦，数量本身就是差异化证据；不用自造压缩语（见 A14）
- **语料依据**（真人原话）：`在 XX 公司担任 XX，然后去了 XX，现在主要负责 XX`（知乎示例）；`毕业后我先进入补教业……工作两年后转换跑道……后来因为想更专注在内容设计，我转到一家科技公司`（口语范例）；`同时他还在干两件事。一，……二，……`（桂姐独白）——转场词全部携带时间/因果/话题信息，无一例"就说这段"式纯结构预告。
- **执行**：写完做**接缝检查**（双向）：① 随机删掉一句，前后句是否仍自然衔接？出现"另外/第二"悬空 = 分点稿，重连；② 反向：哪个转场句删掉后毫无影响 = 编导式转场（A13），删掉它。

### H2 长短句自然交错（节奏，不造锤子）
- **规则**：句长跟着内容自然起伏，逗号链 ≥4 的长句拆开。**不刻意造 mic-drop 短句**——"15 道全对。"式独立收锤是展示腔（A16）；数字结果写在句子里（"调整之后 15 道全部通过"）。短句只在该短的地方出现（自然停顿、简单确认），不是为了节奏设计出来的。

### H3 叙事时间线（视角）
- **规则**：用**相对/场景时间**带故事——大三下/实习第二个月/上线前一周/接手的时候/一开始/那阵子。禁止"在任期间/项目周期内"（总结态），也**不写具体日历时间**（2026 年 X 月、上半年）——日历时间简历上有，口语里说它不携带增量，还占时长。
- **执行**：每个故事写作前先回答"这件事发生在哪个具体节点，之前发生了什么"，用相对说法落位。

### H4 先限制，后成果；至少一处代价（颗粒度）
- **规则**：成果句前必有"当时的限制是…"；全篇至少一处"代价是…/一开始我甚至…后来发现不行"。
- **为什么**：限制是可信度的来源，代价是真实感的来源（对应 A8）。

### H5 口语标记，低密度（3–6 个/篇）
- **词表**：其实 / 当时 / 后来 / 结果 / 说白了 / 挺…的 / 蛮 / 说实话 / 这么说吧。
- **规则**：全篇 3–6 个。0 个 = 扁平（A10）；超过 8 个 = 表演感，删。

### H6 专名 + 数字，数字口语化（颗粒度）
- **规则**：每个故事 ≥1 个专名（公司/产品/工具/场景名）+ ≥1 个数字。**数字用口语口径**：约数优先（"三成多""从两千单到三千单"），除非真实口径就是精确值（"转接率从 42% 到 19%"）。
- **坏例**：`转化率提升了 37.5%`（假精确，没人即兴记住小数点）
- **好例**：`大概提了三成，从每天两千单拉到三千单`

### H7 动词具体到画面
- **词表（合格）**：拆 / 改 / 砍 / 定 / 盯 / 劝 / 吵 / 拉 / 跑（跑数据）/ 压 / 挑 / 蹲（蹲现场）
- **词表（受限）**：负责 / 参与 / 推进 / 协助 / 跟进 / 深入——**"负责"只允许用来报管辖范围**（"主要负责知识库、提示词和评测"——后面必须跟具体范围清单）；不能作为故事的唯一动作描述（"我负责了这个项目"就没了下文 = 不合格）。
- **规则**：报范围用"主要负责 A、B、C"；讲故事时每个故事 ≥2 处"我 + 合格动词"。

### H8 一处自我修正或让步
- **规则**：全篇恰好一处（多了啰嗦）：`这么说吧` / `更准确地说` / `说实话这块我一开始做错了` / `我不太想说"我很匹配"，我更想让您从这件事里自己判断`。
- **为什么**：让步是"人在现场思考"的最强信号。

### H9 钩子收尾，不致谢收尾
- **规则**：最后一句话落在"没讲完但最想被追问"的半句上（`这里最想讲的其实是后来我们怎么改指标的——您感兴趣的话我展开`），"谢谢"二字不出现在结尾。

### H10 一种口吻贯穿
- **规则**：从 `voice-calibration.md` §4 的三种口吻（桂姐=直接敢判断 / Kelly=温和给公式 / 海苔=松弛承认学习）里**选一种**贯穿全篇。拼接感 = 最大的人造痕迹。

### H11 第一句话 = 定位标签，直接说，不加前置框架（活人感的落点）
- **规则**：开场一口气完成三件事——`面试官你好，我叫 XX，来自 XX 大学，一个XX的……经理/产品人`。学校以"来自 XX 大学"紧贴在标签前，**不独占一句**；标签**直接说判断**，不加任何前置框架（"一句话说我是个什么样的人：""如果要给我贴个标签"全部禁用——那仍在预告"我要说话了"）。
- **差异化的三个来源**（Kelly：锚定绝对优势 + 构建壁垒；标签的差异化只能从这三处来）：
  1. **可命名的专长**——一门别人没有的手艺（如"把评测当手艺"：每段实习都在搭评测、拆 badcase）
  2. **稀有的交叉**——专业 × 岗位的组合（如能源动力工程 × AI 产品）
  3. **数量/覆盖**——四段实习 / 两次从零到一（盘点句"我有 N 段 X 相关的实习"本身是证据）
  **"不迷信 X、先查 Y"这类人人可说的方法论判断不构成差异化**——它可以当故事里的判断句，不能当标签。
- **为什么**：最贵的 15 秒在第一句。前置框架浪费一拍；无差异化的标签浪费整句——面试官听完记不住你和别人的区别。
- **句式模板**：`我是一个（专长/交叉）的……人，+ 盘点句（我有 N 段 X 相关的实习，其中最核心的一段是在 X 做 Y，主要负责 Z）`
- **活人感检验**：这句话说出口，面试官愿不愿意顺势追问一句"为什么这么说"？愿意 = 标签立住了；不愿意 = 换标签。
- **好例**：`面试官好，我叫小林，来自一所理工类大学，一个把评测当手艺的 AI 产品经理。我有四段 AI 相关的实习，主要涵盖电商导购、智能外呼、文档识别和创作者社区这些方向。其中最核心的是在一家电商大厂，负责 C 端导购 Agent 的知识库、提示词和评测。`
- **坏例**：① `一句话说我是个什么样的人：……`（前置框架，直接删）；② `我是一个不迷信模型、先查链路的 AI 产品人`（人人可说的方法论判断，无专长、无交叉、无数量——不构成差异化）

### H12 朴素因果链（手段→成果，报经历的默认形态）
- **规则**：成果句的标准形态就是 `通过【名词级手段】，把【指标】从 A 提升到 B`——`通过重构知识库和优化多路召回，把咨询下单转化率从 30.2% 提升到 37.5%`。手段用名词短语（重构知识库 / 优化召回 / 调分块策略 / 搭评测集），**禁止模糊动量词短语**——"重做了一轮""做了一轮迭代""下手做了""搞了一波"：既不是手段也不是成果，是凑出来的动词壳。不设悬念、不先抑后扬、不写金句、不做首尾呼应的设计（A15 的正向面）。
- **检验**：全篇扫描一遍，每句话回答两个问题——它携带信息吗？删掉它故事缺损吗？两问都"否"的句子就是修辞句，删。

### H13 留白给追问（自我介绍是菜单，不是正餐）
- **规则**：自我介绍只讲到**第一层**——范围（负责什么）+ 领域名词（知识库/召回/提示词/评测/灰度）+ 结果数字。操作细节（分几类、什么算法、几套模板、怎么归因）**刻意不说**——"怎么做的"正是面试官要问的题，别替他提前答完。手段→成果（H12）照样成立，只是手段停在**领域名词级**："从知识库和召回下手"，而不是"四类切片入库、三路召回"。
- **三层详略**：
  1. 90 秒版：结果 + 名词。每提到一个名词 = 开一扇门
  2. 3 分钟版：+第一层手段（做了哪几类事）
  3. 决策与取舍层（为什么这么做 / 换方案行不行 / 代价是什么）：**永远留给追问**，备在故事卡的三层追问预案里
- **判据**（写完必答）：面试官听完这段，最想追问的 3 个问题是什么？这 3 个问题你必须都有 ≥3 分钟弹药。答不上 → 补弹药，或把这个名词从稿里拿掉。反向：如果稿里已把"怎么做的"讲完，面试官没得问 → 讲太满，砍细节。
- **为什么**：自我介绍是全场唯一由你决定他问什么的环节。讲太满，他只能问你不准备的区域；留白留在他弹药最足的区域，整场面试的题目就是你出的。

### H14 每句话过"为什么是我"筛（总检验，最高优先级）
- **规则**：自我介绍里任何一句话都不是废话——每句话都要回答"我为什么适配这个岗位、为什么是我而不是别人"。定稿前逐句标注"这句在证明______"，标不出的句子删掉，或补上价值挂钩。
- **价值链必须闭合（三段一个不能少）**：`事实 → 能力/眼界（它给了你什么）→ 岗位意义（这个能力用在这岗位上意味着什么）`。
  - ✅ 闭合：`社长，长期泡在 AI 创作者和重度用户堆里——普通用户拿 AI 干什么、卡在哪，我有一手感觉，做产品判断时不靠猜`（事实→一手用户感觉→判断不靠猜）
  - ❌ 半开链（等于没挂）：`社长，长期泡在 AI 创作者和重度用户堆里`（"所以呢？有什么用？"——没说到它给了你什么能力）
  - ❌ 半截信息：`社长，带着两百多人的社群`（"两百人社群"不证明适配，只是占时长）
- **数字的相关性**：数字本身必须即岗位证据（`帮二本同学上岸字节`=产品化能力+结果）；与岗位无关的数字（AI 产品岗挂"视频 11.8 万播放"）是废话，换运营岗才成立。
- **执行**：定稿前全篇逐句标注"这句在证明______"，标不出的句子删掉。

## §3 最高规则：公式内隐，不是公式外显

**六段公式（定位→证据→动机→钩子）是生成和检查用的骨架，不是输出格式。**

- 模型死板的根源：把骨架当模板填空，输出就带着骨架的形状（六块、序号、标签）。
- 正确流程：骨架只存在于工作台区和检查清单里；**开讲版里公式的痕迹必须全部抹掉**——六段之间看不出接缝，转场是内容与内容之间的关系。
- **反直觉但必须执行**：一篇合格的开讲版，把公式标签全部藏起来之后，仍然能被检查者反推出六要素齐全（用 lint 脚本的工作台锚点核对），但听众听不出来。

## §4 两遍写作法（生成协议）

**顺序不能反——先套公式再填空 = 必死板。**

1. **第一遍（讲故事）**：不看公式、不看模板。用"讲给朋友听"的语气，把定位和两个故事讲成自然的话，允许啰嗦、允许超时。此遍的语气就是成稿的语气。
2. **第二遍（套公式压时长）**：拿出六要素 checklist 逐项核对（缺哪段补哪段），再按 4 字/秒压到目标时长；压缩时**只删信息，不改语气**——删掉的是事实条目，不是把口语腔换回书面腔。
3. **朗读测试**：出声读一遍（4 字/秒）。喘不上气的地方断句；读起来自己起鸡皮疙瘩的句子删掉重写。

## §5 完整对照：坏例 → 好例（同一份素材）

**❌ 坏例（典型 AI 输出：A1 结构外显 + A2 元框架 + A3 收尾腔 + A5 垫场 + A9 泛指 + A12 总结态）**

> 面试官您好，我叫小李。下面我将从三个方面介绍自己：
> 1. **专业能力**：具备扎实的数据分析与产品思维能力，熟练掌握 SQL、Python；
> 2. **项目经历**：曾在某互联网公司实习，参与 AI 客服产品优化项目，负责需求分析与跨部门协同，实现了显著的业务提升；
> 3. **求职动机**：非常认可贵司的技术氛围与发展平台，希望能有机会加入。
> 以上就是我的自我介绍，谢谢！

**✅ 好例（同一信息，拟人版：一段话，公式全部内隐，第一句贴标签）**

> 面试官好，我叫小李。我是一个非得跑到现场、把流程捋顺才踏实的准产品人，会计转专业，大三。最想讲的一段，是在一家做电商 SaaS 的公司实习那两个月。当时客服组一天三千条咨询，回复要四个小时。组里就我一个产品。也没有标注数据。我先人工抽了两百条，把问题拆成三类，发现一半咨询其实集中在七个问题上，就先做了个 FAQ 检索。结果两周后，回复时间压到一小时以内。这段经历让我确定想做 AI 产品——说白了它不是调 API，是先搞清楚人到底在问什么。剩下的时间如果您感兴趣，我可以讲讲当时指标选错了、后来怎么改的故事。

（自检对照 §8：第一句是定位标签不是报家门（H11）；无结构标记；"组里就我一个产品。"短句落锤；"当时/那两个月/两周后"叙事时间线；"就我一个产品/没有标注数据"限制先行；"其实/结果/说白了"口语标记 3 个；"指标选错了"代价与让步；数字口语口径（三千条/两百条/一小时）；钩子收尾。）

**逐句注释（改了什么，为什么）**：
- `下面我将从三个方面` → 删（A2）。第一句直接给身份 + 转折（"会计转产品"自带记忆点）。
- `1. 2. 3.` 分点 → 连续叙述，转场靠内容（"最想讲的一段是…""这段经历让我确定…"）（A1/H1）。
- `扎实的…能力/熟练掌握` → 删形容词，直接让事件证明（A5）。
- `某互联网公司/AI 客服产品优化项目/显著的业务提升` → `电商 SaaS 公司/一天三千条/从四小时到一小时`（A9/H6：专名 + 具体数字 + 口语化对比）。
- `实习期间我负责…` → `实习那两个月——当时…组里就我一个产品，还没有标注数据`（A12/H3/H4：总结态 → 叙事态，限制先行）。
- `实现了显著的业务提升` → `两周后回复时间压到一小时以内`（A6：名词化 → 我+动词+结果）。
- `认可贵司技术氛围` → 删（红线：万能动机）。动机融进判断句"它不是调 API，是先搞清楚人到底在问什么"。
- `以上就是…谢谢` → 钩子半句收尾（A3/H9）。
- 节奏：长短交错，`组里就我一个产品，还没有标注数据。`短句落锤（H2/A11）。

## §6 输出协议（模型交付格式规定）

1. **唯一交付物是「开讲版」**：一到两段连续文字，放在引用块或代码块里整段给出。
2. 开讲版内**禁止**出现：markdown 标题、加粗、列表符号、序号、【】标签、括号注释、「背景：/问题：」字段冒号。
3. 结构锚点（【核心人设】等）只允许出现在文件的**工作台区**，供 lint 脚本核对结构；工作台区允许分点——**分点这一行为本身只属于素材整理，不属于成稿**。
4. 对话中不要逐段配小标题解说"这段是定位、这段是证据"——讲解放在交付之后单独说。

## §7 何时允许例外

- 用户明确要"结构化速览版"（比如面试前 30 秒瞄一眼的小抄）：可以给 bullet 版，但必须同时提供开讲版，且注明速览版仅供自己看、禁止照念。
- 3 分钟版与 90 秒版同理：都是连续口语，只是故事展开深度不同。
