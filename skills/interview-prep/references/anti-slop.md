# 反 Slop 检测（17 条中文签名 + 禁用词表）

**为什么有这一页**：框架对了 ≠ 稿子能听。听众的原话是"会被问你这个自我介绍是不是 AI 写的"。AI 味可以被**机械识别**，所以这里给出固定签名和确定性判据，不留"感觉不错"的空间。

改编自 `slop-detector`（10 条签名、分层定级）与 `voice-check`（don't-list 正则表），已换成中文面试场景的判据。

**使用时机**：Step 3 写完自我介绍**必须**跑 `scripts/lint_intro.py`（脚本内置了下表的 Tier-1/Tier-2 判据），报告里有 ❌ 就不许交付。

---

## 17 条签名（固定清单，逐条标 clean / flagged）

| # | 签名 | 确定性判据 | 层级 |
|---|---|---|---|
| S1 | 元框架开场 | 首段出现"我将从三个方面/接下来我将/大家好我是…接下来" | **Tier-1** |
| S2 | 列表撑论点 | 删掉分点后论点就不成立（全靠"首先/其次/最后"支撑） | **Tier-1** |
| S3 | 名词化堆砌 | 每 100 字 >3 个抽象名词化结构（"进行了…的赋能/落地/优化/打通"） | Tier-2 |
| S4 | 泛化例子 | 只有"某公司/一个项目/相关工作"，无具体名、数字、时间 | Tier-2 |
| S5 | 无第一人称 | 通篇"我们团队"，找不到"我+具体动作动词" | Tier-2 |
| S6 | 提示词残留 | "总的来说/以上就是我的自我介绍/希望有机会加入贵司/谢谢聆听" | **Tier-1** |
| S7 | 提纲式段落 | >60% 段落都是"总起 + 三句支撑 + 收尾"同一形状 | Tier-2 |
| S8 | 模糊限定堆 | 50 字内 ≥2 个"可能/大概/某种程度上/一定程度上" | Tier-2 |
| S9 | 黑话堆砌 | 单篇 ≥3 个（赋能/抓手/闭环/打法/颗粒度/对齐/心智/沉淀/护城河） | Tier-2 |
| S10 | 不确定性被抹平 | 全篇无一处限制、代价、失败或反转（原方法论要求"先讲限制"） | Tier-2 |
| S11 | 结构外显 | **成稿（开讲版）中出现任何**：序号（①/1./第一）、列表符号、小标题、加粗、【】标签、「背景：/问题：」字段冒号 | **Tier-1** |
| S12 | 逗号链过长 | 单句逗号 ≥4，出声读会憋气，拆成两句（短句不强制——刻意造 mic-drop 收锤是 S16 金句腔） | Tier-2 |
| S13 | 编导式转场 | 转场句在播报结构而非推进内容（就说这段/轮到交互/话锋一转/从头讲）；删掉后前后仍直接相连 | Tier-2 |
| S14 | 术语泄漏 | 工作台行话进了成稿（最硬的/深水区/弹药/埋钩子/北极星/贴标签）；报经历应用「最核心的一段是在 X 做 Y，主要负责 Z」 | Tier-2 |
| S15 | 刻意修辞桥 | 为效果而非信息服务的句子：悬念句（那三个月我没先碰模型）/反转句（这 37.5% 不是调模型调出来的）/设计回指（我开头那句话就是这么来的）；删掉后信息无损即删，报经历=手段→成果 | Tier-2 |
| S16 | 模糊动词壳 | 既非手段也非成果的动量词短语（重做了一轮/做了一轮迭代/下手做）；成果句=「通过【名词级手段】，把【指标】从 A 提升到 B」 | Tier-2 |
| S17 | 具体日历时间 | 自我介绍里出现 2026 年 X 月/上半年——简历上有，口语不携带增量；用相对/场景时间（接手的时候/一开始/那阵子） | Tier-2 |

**定级规则**：Tier-1（S1/S2/S6/S11）任一命中 = ❌ 硬性不合格；Tier-2 命中 ≥3 条 = ❌；1–2 条 = ⚠️ 必须人工改写确认。

> S11 是"自我介绍被拆成几个点、像分点答题"的直接判据：公式骨架（定位/证据/动机/钩子）是生成与检查用的**内隐骨架**，绝不允许以任何形状出现在成稿里。完整规范见 `references/human-voice-spec.md`（AI 味 16 特征 A1–A16 + 拟人 14 特征 H1–H14 + 两遍写作法）。

## 禁用词表（don't-list，命中即需改写）

| 类别 | 禁用 | 为什么 |
|---|---|---|
| 喊口号 | 匹配 / 非常适合 / 完全符合 / 我很契合 | 喊出来就是邀请面试官反驳你（A3 00:04） |
| 空泛优势 | 逻辑强 / 沟通好 / 学习能力强 / 抗压能力强 / 有责任心 | 零信息量，必须让经历自己带出来 |
| 万能动机 | 贵司平台大 / 技术氛围好 / 发展空间大 | 换任何一家都成立 = 没说 |
| 黑话 | 赋能 / 抓手 / 闭环 / 打法 / 颗粒度 / 沉淀 / 心智 | 见 S9 |
| 结构套话 | 首先/其次/最后 / 总的来说 / 综上所述 / 以上就是 | 见 S1/S6 |
| 模糊量化 | 大幅提升 / 显著改善 / 效果很好 / 得到了认可 | 见 S4，必须给数字或三种定性替代 |

## 坏样例 vs 好样例（同一段经历）

**❌ 坏样例（Tier-1 命中 3 条 + Tier-2 命中 4 条）**

> 大家好，我是小明，接下来我将从三个方面介绍自己。首先，我具备较强的数据分析能力和用户洞察能力；其次，在某公司实习期间，我参与了数据产品的相关工作，负责需求梳理与跨部门协同，实现了业务闭环，效果显著；最后，我非常认可贵司的平台和技术氛围，希望有机会加入贵司。总的来说，我认为自己很匹配这个岗位。

命中：S1（接下来我将从三个方面）、S2（首先其次最后）、S6（总的来说/希望有机会）、S3（实现了业务闭环）、S4（某公司/相关工作）、S9（闭环）、禁用词（很匹配/平台/技术氛围）。

**✅ 好样例（原文口径）**

> 如果要给我贴一个标签，我是一个把 AI 用在具体业务问题上、并且一定要跑到数据的人。
> 最相关的一段是在 XX 做客服 Agent。当时的限制是只有我一个产品、两周上线，而且没有任何标注数据。我先用一个 200 条的人工集把 badcase 拆成检索失败、意图误判、知识缺失三类，再针对性改召回策略。上线三周，人工转接率从 42% 降到 19%。
> 代价是我为了指标好看，初期把兜底阈值调高了，用户信任度反而掉了——这件事我最想讲的其实是后来我们怎么重新定义指标。

命中项：0 条。特征：标签开场、先讲限制、数字带时间单位、有"我+动作动词"、暴露代价、钩子留白。

## 与脚本的关系

`scripts/lint_intro.py` 已内置：S1/S6（正则）、S9（黑话计数）、禁用词表、S4（泛化短语）、S5（"我+动词"检测）、S10（限制词检测）、S3（名词化后缀计数）、S11（结构标记正则）、S12（短句/逗号链节奏检测），外加拟人正向检查（叙事时间标记 / 口语标记计数 / 让步修正）。
**扫描区域**：模板中 `<!-- speech:start --> … <!-- speech:end -->` 标记的「开讲版」区域（无标记则扫全文）。六要素锚点检查仍看全文件（锚点只存在于工作台区）。
S2、S7、S8 需人工判断（脚本给提示词，不自动判）。脚本没覆盖的部分，按本页表格人工过一遍。
