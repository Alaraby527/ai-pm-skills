# 面试备战提示词合集

## 1. 项目 5 维度梳理

```
请帮我按 5 维度梳理以下项目，生成标准化面试素材：

【项目描述】
{project_text}

请按以下维度输出：
1. 项目背景：行业现状、业务天花板、用户刚需
2. 项目目标：核心指标 + 提升逻辑 + 数据预估依据
3. 产品方案：策略分层设计，每条设计对应需求与权衡
4. 难点 & 亮点：矛盾平衡、创新解法、跨部门推动
5. 结果 & 复盘：实际数据 vs 目标、可复用方法论、踩坑教训

每个维度准备 3 分钟版和 15 分钟深挖版。
```

## 2. 模拟面试

```
你现在是一位{company}{role}岗位的面试官，风格{style}。
我的背景是：{background}
目标岗位 JD：{jd}

请进行一轮模拟面试：
- 每次只问一个问题
- 根据我的回答追问（最多追问 2 层）
- 覆盖项目深挖、行业认知、行为面试、AI PM 专项
- 面试结束后给出：整体评价 + 每个问题的改进建议 + 评分
```

## 3. 行业认知题框架

```
请用以下框架帮我准备关于"{topic}"的行业认知题回答：

竞品差异化题：业务定位 → 目标用户 → 产品设计逻辑 → 增长打法
行业趋势判断题：行业规模&增速 → 线上化率 → 政策影响 → 用户需求变化 → 机会判断
落地方案题：核心问题定位 → 方案推导 → 优先级排序 → 预期效果

要求：观点明确，有数据支撑，不罗列事实。
```

## 4. STAR+R 行为题准备

```
请用 STAR+R 框架帮我准备以下行为面试题：

题目：{question}
我的经历：{experience}

S（情境）：具体背景
T（任务）：你的目标
A（行动）：你具体做了什么（重点，占 50%）
R（结果）：量化结果
+R（反思）：学到了什么、如果重来会怎么做

总长度控制在 2 分钟以内。
```

## 5. 面试复盘：完整还原引导

```
请帮我复盘这场面试。我会提供面试回忆，你帮我按以下结构整理：

1. 面试基本信息：公司/岗位/轮次/时长
2. 问题清单：每个问题 + 我的回答摘要 + 面试官反应
3. 自我感觉：哪里答得好、哪里卡壳、哪里紧张
4. 面试官追问点：追问了什么（= 可能没答到点上）

请先不要评判，帮我客观还原。还原后再做诊断。
```

## 6. 面试复盘：漏斗诊断

```
请根据以下求职数据诊断我的转化率短板：

- 投递简历数：{applied}
- 获得面试数：{interviews}
- 一面通过数：{first_pass}
- 二面通过数：{second_pass}
- 终面通过数：{final_pass}
- Offer 数：{offers}

请计算各层转化率，对比行业均值（简历→面试 20%、一面通过 35-40%、二面通过 30-35%、终面通过 70-80%），定位最低于均值的环节，给出根因假设和验证方法。
```

## 7. 面试复盘：短板分类与改进

```
请根据以下面试复盘，对问题进行分类并给出改进方案：

【面试复盘记录】
{retro_notes}

请按以下格式输出：
1. 显性短板（不会的知识点）：清单 + 学习方法 + 验证标准
2. 隐性短板（没深度/没数据）：清单 + 改进方法 + 验证标准
3. 表达短板（说不清楚）：清单 + 练习方法 + 验证标准
4. 匹配短板（没让面试官感知到）：清单 + 调整策略

每个短板给出优先级（P0/P1/P2），P0 问题必须在下一场面试前解决。
```
