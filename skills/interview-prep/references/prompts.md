# 面试备战提示词合集

## 1. 项目 5 维度梳理

```
请帮我按 5 维度梳理以下项目，生成标准化面试素材：

【项目描述】
{project_text}

请按以下维度输出：
1. 项目背景：行业现状、业务天花板、用户刚需
2. 项目目标：核心指标 + 提升逻辑 + 数据预估依据
3. 产品方案：策略分层设计，每条设计对应需求与权衡
4. 难点 & 亮点：矛盾平衡、创新解法、跨部门推动
5. 结果 & 复盘：实际数据 vs 目标、可复用方法论、踩坑教训

每个维度准备 3 分钟版和 15 分钟深挖版。
```

## 2. 模拟面试

```
你现在是一位{company}{role}岗位的面试官，风格{style}。
我的背景是：{background}
目标岗位 JD：{jd}

请进行一轮模拟面试：
- 每次只问一个问题
- 根据我的回答追问（最多追问 2 层）
- 覆盖项目深挖、行业认知、行为面试、AI PM 专项
- 面试结束后给出：整体评价 + 每个问题的改进建议 + 评分
```

## 3. 行业认知题框架

```
请用以下框架帮我准备关于"{topic}"的行业认知题回答：

竞品差异化题：业务定位 → 目标用户 → 产品设计逻辑 → 增长打法
行业趋势判断题：行业规模&增速 → 线上化率 → 政策影响 → 用户需求变化 → 机会判断
落地方案题：核心问题定位 → 方案推导 → 优先级排序 → 预期效果

要求：观点明确，有数据支撑，不罗列事实。
```

## 4. STAR+R 行为题准备

```
请用 STAR+R 框架帮我准备以下行为面试题：

题目：{question}
我的经历：{experience}

S（情境）：具体背景
T（任务）：你的目标
A（行动）：你具体做了什么（重点，占 50%）
R（结果）：量化结果
+R（反思）：学到了什么、如果重来会怎么做

总长度控制在 2 分钟以内。
```
