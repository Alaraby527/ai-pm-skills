# 09 通用题 — {{COMPANY}} · {{ROLE}}

> 16 道通用题，每题一条 60–90 秒可念答案。写不出来的一类 = 面试必死的一类，先补这一类。
> 统一公式：**一句话结论 → 一个具体案例（背景 / 冲突 / 行动 / 结果）→ 一句反思或回扣岗位**。
> 读法：先读 `references/common-questions.md` 对应章节，再填这张卡；写完出声读一遍，超过 90 秒就删信息，不许加速。

- **我最容易被攻击的三个点**（学历 / 空窗 / 数据 / 经验 / 跳槽…）：① ___ ② ___ ③ ___

## 一、个人信息

### 1. 自我介绍
→ 不在这里写。直接用 `03-自我介绍稿.md` 的开讲版，并跑 `lint_intro.py`。

### 2. 你最大的优点是什么？
- 考察点：岗位需要的特质，你有没有证据
- 骨架：优点（名词级）→ 一个具体案例 → 结果 → 对岗位的意义
- 我的答案（60 秒）：___
- 禁忌：形容词堆砌（认真负责、学习能力强）；优点与岗位无关
- 追问预案：这个优点给你带来过什么代价？ / 举一个它没起作用的例子？

### 3. 你最大的缺点是什么？
- 考察点：自我认知 + 是否致命 + 有没有改进
- 骨架：真实但非致命的缺点 → 具体表现 → 已采取的改进动作 → 现在的结果
- 我的答案（60 秒）：___
- 禁忌：「太追求完美 / 太拼」；价值观类缺点；销售岗说自己不会沟通这类致命伤
- 追问预案：现在改善到什么程度？ / 这个缺点影响过工作吗？

### 4. 你认为你的核心竞争力是什么？
- 考察点：公司凭什么录用你（不是技能罗列）
- 骨架：一句话定位 → 2 个证据（案例 + 数据）→ 与岗位的直接关系
- 我的答案（60 秒）：___
- 禁忌：把"会用某工具"当核心竞争力；和别人可完全互换的描述
- 追问预案：团队里别人也有这个能力，你的差别在哪？ / 换个业务还能用吗？

### 5. 你最近 5 年的职业规划是什么？
- 考察点：上进心、目标感、稳定性
- 骨架：为什么选这个行业/岗位 → 3 年做到什么 → 5 年方向 → 为此现在在做什么
- 我的答案（60–90 秒）：___
- 禁忌：只说"想当管理者"；规划与岗位无关；说"还没想好"
- 追问预案：如果 3 年没升上去怎么办？ / 这个规划和我们岗位的关系是什么？

### 6. 别人对你的评价是什么？
- 考察点：性格、人际、自我认知是否客观
- 骨架：一句公认评价 → 一个能证明它的小故事 → 一个无伤大雅的小毛病
- 我的答案（60 秒）：___
- 禁忌：全是好评像自夸；编朋友的话
- 追问预案：有没有负面评价？ / 谁最了解你，他会怎么说？

## 二、工作经历

### 7. 你以往工作中遇到最大的困难是什么，怎么处理的？
- 考察点：抗压、抓关键矛盾、解决问题的方法
- 骨架：困难是什么（一句）→ 为什么难 → 我做了什么（重点）→ 结果 → 复盘
- 我的答案（90 秒）：___
- 禁忌：说"没遇到过"；把团队困难说成个人困难；只有情绪没有动作
- 追问预案：当时有没有别的解法？ / 如果重来会怎么做？

### 8. 你上一家公司的离职原因是什么？
- 考察点：职业规划认知、责任心、稳定性、人际关系
- 骨架：客观原因（一笔带过）→ 个人发展诉求（具体）→ 对新平台的期许（具体到业务）
- 我的答案（60–90 秒）：___
- 禁忌：吐槽前公司/领导；只说钱；说"和同事处不来"
- 追问预案：如果新公司也有这个问题呢？ / 当时有没有内部转岗机会？

### 9. 你希望与什么样的上级共事？
- 考察点：自我要求、适配度
- 骨架：多谈对自己的要求 → 少谈对上级的风格要求 → 一句"适应能力"
- 我的答案（45–60 秒）：___
- 禁忌：给上级列条件（别微观管理、别加班）；说"都行"显得没想法
- 追问预案：如果上级风格完全相反呢？ / 你适应过最难相处的上级是谁？

### 10. 你做过哪件事，你认为比较成功？
- 考察点：成就观、总结能力、价值观
- 骨架：一句话说结果 → 背景与难点 → 我的关键动作 → 数据结果 → 沉淀的方法
- 我的答案（90 秒）：___
- 禁忌：自我表彰式罗列；成功与岗位无关；没有"我"的动作
- 追问预案：这件事里运气的成分有多少？ / 换成别人能做成的概率多大？

## 三、应聘相关

### 11. 你了解过我们公司吗？
- 考察点：重视程度、是否海投
- 骨架：一句业务定位 → 一个近期具体动作 → 我的判断 → 与我的关系
- 我的答案（45–60 秒）：___
- 禁忌：只背官网介绍；谈薪资福利；说"听说过，很有名"
- 追问预案：你觉得我们最大的问题是什么？ / 和竞品比呢？

### 12. 为什么来应聘这个岗位？
- 考察点：岗位理解、动机、匹配度
- 骨架：能力匹配（证据）→ 职业规划（为什么是现在）→ 为此做的行动（研究/学习/交流）
- 我的答案（60–90 秒）：___
- 禁忌：平台大/氛围好/离家近；只说"我想学习"
- 追问预案：你还投了哪些岗位？ / 如果这个岗位和你预期不一样呢？

### 13. 你能为我们带来什么？
- 考察点：自我定位、价值意识、落地能力
- 骨架：进来先解决什么（具体）→ 怎么做（路径）→ 3–6 个月的可验证结果 → 长期增量
- 我的答案（60–90 秒）：___
- 禁忌：空喊忠诚/吃苦；承诺做不到的事；把团队成果算成自己的
- 追问预案：这些事现在团队里没人做吗？ / 你凭什么能做成？

### 14. 最快什么时候可以入职？
- 考察点：求职紧迫度、是否有其他选择、交接是否负责
- 骨架：表达意愿 → 给确定时间 → 说明交接安排（在职）或随时到岗（离职）
- 我的答案（30–45 秒）：___
- 禁忌：说"随时都行"（显得急、易被压价）；主动说"还有别的 offer"
- 追问预案：能不能提前？ / 离职证明什么时候能拿到？

### 15. 你的期望薪资是多少？
- 考察点：自我价值认知、市场行情
- 骨架：先反问对方薪资定位 → 给区间（不低于底线）→ 给依据（经验/技能/行情）→ 留弹性
- 我的答案（45–60 秒）：___
- 禁忌：报"看公司安排"；报一个远高于市场的数却不给依据；先自降
- 追问预案：如果我们只能给到区间下限呢？ / 你上一份薪资是多少？

### 16. 你有什么问题想要问我的吗？
- 考察点：主动性、研究深度、价值观
- 骨架：问业务/团队/岗位挑战/评估方式，不问百度能查的
- 我的 3 个问题：① ___ ② ___ ③ ___
- 禁忌：说"没有"；问薪资福利加班；问能百度到的信息
- 追问预案：（对方反问"你还有什么想了解的吗"）→ 回到岗位前 3–6 个月的最大挑战
