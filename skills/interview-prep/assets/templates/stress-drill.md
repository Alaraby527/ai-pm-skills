# 10 压力面 — {{COMPANY}} · {{ROLE}}

> 压力面不是"猜难题"，是练**被否定、被连环追问、被沉默施压**时的反应。
> 使用方式：先读 `references/stress-interview.md`，再用本卡做 1 轮演练并打分；重点不是答对，是**接住**。
> 四步口诀：**接住（不辩不怂）→ 澄清 → 给证据或推理 → 留余地**。

## 三、现场话术速查（背到能脱口而出）

| 场景 | 话术 |
|---|---|
| 被直接否定 | "您说的这部分确实存在，我先接住。我实际的情况是 ___，所以我当时的判断是 ___。" |
| 被质疑数据 | "这个数是 ___ 口径下的，基线是 ___，同期没有其他大改动；如果要归因，我可以拆开讲。" |
| 两难选择 | "两个都有道理，关键看阶段。以现在的阶段我会优先 ___，因为 ___；如果条件变了，我会 ___。" |
| 完全不会 | "这是我的盲区。基于现有理解我会先 ___，不对请您指正，我回去补上再发给您。" |
| 沉默冷场 | "我先小结一下刚才两点：___ 和 ___。您更关心哪一块，我再展开。" |
| 被比较/贬低 | "我确实不是最像的候选人，但我能带进来的是 ___，这一点在 ___ 上有证据。" |
| 被问其他 offer | "目前有几个流程在走，但我更看重这个岗位的 ___，所以今天准备了 ___。" |
| 被追问到没准备 | "这个细节我当时没有记数据，能讲的是过程和判断；数字我回去核实后补充。" |
