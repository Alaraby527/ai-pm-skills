# 03 自我介绍逐字稿 — {{COMPANY}} · {{ROLE}}

> ⚠️ 交付前必须跑体检：`python3 ~/.workbuddy/skills/interview-prep/scripts/lint_intro.py 03-自我介绍稿.md --target 90`
> 六个【】标记是结构锚点，体检脚本按它们判定结构完整性，**不要删除标记本身**。

## 90 秒版

**【核心人设】**（≤15s，一句话标签 + 记忆锚点，必须与 JD 匹配）

> 面试官好，我是 ___。如果要给我贴一个标签，我是 ___。

**【硬核故事A：专业硬实力】**（≈35s，限制 → 我的判断/行动 → 量化结果）

> 最相关的一段是 ___。当时的限制是 ___（人/时间/数据/预算），真正的难点是 ___。
> 我的做法是 ___（讲决策，不要罗列动作）。
> 结果是 ___（对比基线：从 X 到 Y）。

**【硬核故事B：软素质】**（≈25s，冲突 → 我如何协调/推动 → 团队层面的结果）

> 另一件事能说明我怎么推动事情：___。冲突在于 ___，我做了 ___
> （把争议变成一个可验证的小实验 / 对齐口径 / 拆优先级），最后 ___。

**【生命力彩蛋】**（≈5s，一句话，不展开）

> 另外 ___（长期坚持的事 / 独特输入）。

**【动机】**（≈15s，必须具体，禁止"平台大""技术氛围好"）

> 我没有海投。我注意到贵司 ___（某个具体业务动作），它的 ___ 还停留在
> ___，这正好是我上一份工作踩过坑、也解决过的地方。

**【钩子】**（≈10s，埋一个能聊 3 分钟以上、且是你最强的点）

> 这个项目里我最想讲的其实是 ___（深水区 / 失败复盘 / 业务判断）。
> 如果您感兴趣，我可以展开讲。

**【收尾】**

> 以上是我的基本情况。

## 交付前自查（打勾才能交付）

- [ ] 全文没有出现「匹配 / 非常适合 / 完全符合 / 我很契合」
- [ ] 没有出现空泛优势词（逻辑强 / 沟通好 / 学习能力强 / 抗压能力强）
- [ ] 两个故事都有数字或明确的定性替代证据
- [ ] 故事 B 讲的是"我做了什么"而不是"我们做了什么"
- [ ] 动机具体到这家公司的某个业务判断
- [ ] 钩子是我最想被追问、且能撑 3 分钟的点
- [ ] 体检脚本全部 ✅ / ⚠️，无 ❌
