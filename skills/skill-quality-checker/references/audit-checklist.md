# 8 维度审计检查清单

## D1 可调用性（15%）

| # | 检查项 | 0 分 | 3 分 | 5 分 |
|---|--------|------|------|------|
| 1.1 | frontmatter 有 name 字段 | 缺失 | 有但不规范 | 规范且与目录名一致 |
| 1.2 | description 说清"干什么" | 缺失/模糊 | 有描述但不精确 | 一句话说清核心能力 |
| 1.3 | description 包含触发词 | 无触发词 | 有但覆盖不全 | 覆盖 5+ 种自然表达 |
| 1.4 | 触发场景无歧义 | 与其他 Skill 重叠 | 基本清晰 | 边界明确，不会误触发 |
| 1.5 | 有"触发场景"章节 | 缺失 | 有但简单 | 列出 5+ 典型场景 |

## D2 输入规范（10%）

| # | 检查项 | 0 分 | 3 分 | 5 分 |
|---|--------|------|------|------|
| 2.1 | 定义了必需信息 | 缺失 | 有但不全 | 明确列出 2+ 必需项 |
| 2.2 | 定义了可选信息 | 缺失 | 有 | 列出可选项及默认值 |
| 2.3 | 信息不全时有追问话术 | 无 | 有但笼统 | 每个缺失项有具体追问句 |
| 2.4 | 输入格式要求明确 | 无 | 部分 | 明确格式/类型/范围 |

## D3 输出规范（10%）

| # | 检查项 | 0 分 | 3 分 | 5 分 |
|---|--------|------|------|------|
| 3.1 | 定义了输出物 | 缺失 | 有描述 | 明确输出物类型和结构 |
| 3.2 | 有输出模板 | 无 | 有但简陋 | references/ 有完整模板 |
| 3.3 | 输出格式可预期 | 不可预期 | 基本可预期 | 每次输出结构一致 |
| 3.4 | 有输出质量标准 | 无 | 有 | 明确"好的输出长什么样" |

## D4 异常兜底（15%）

| # | 检查项 | 0 分 | 3 分 | 5 分 |
|---|--------|------|------|------|
| 4.1 | 有异常兜底章节 | 完全缺失 | 有但 < 3 种情况 | 覆盖 5+ 种异常 |
| 4.2 | 信息不全的处理 | 无 | 有 | 有具体追问话术和降级方案 |
| 4.3 | 执行失败的处理 | 无 | 有 | 有重试/降级/转人工方案 |
| 4.4 | 数据缺失的处理 | 无 | 有 | 明确"无数据时不编造" |
| 4.5 | 兜底方案可执行 | 无 | 笼统 | 每个异常有具体操作步骤 |

## D5 工作流完整性（15%）

| # | 检查项 | 0 分 | 3 分 | 5 分 |
|---|--------|------|------|------|
| 5.1 | 有明确的步骤序列 | 无 | 有但 < 3 步 | 5-6 步，逻辑递进 |
| 5.2 | 每步有明确产出 | 无 | 部分有 | 每步都有 output 定义 |
| 5.3 | 步骤可执行 | 纯理论 | 基本可照做 | 具体到"做什么、怎么做" |
| 5.4 | 有检查点/验证环节 | 无 | 有 | 关键步骤有明确检查标准 |
| 5.5 | 步骤间有逻辑递进 | 跳跃 | 基本连贯 | 前一步输出是后一步输入 |

## D6 单一职责（10%）

| # | 检查项 | 0 分 | 3 分 | 5 分 |
|---|--------|------|------|------|
| 6.1 | Skill 只干一件事 | 3+ 不相关功能 | 2 个相关功能 | 高度聚焦 |
| 6.2 | 触发场景聚焦 | 发散 | 基本聚焦 | 所有触发词指向同一任务 |
| 6.3 | 输出物统一 | 多种不相关输出 | 基本统一 | 同一类型输出物 |
| 6.4 | 可独立使用 | 依赖其他 Skill | 部分依赖 | 完全自包含 |

## D7 方法论还原度（15%）

| # | 检查项 | 0 分 | 3 分 | 5 分 |
|---|--------|------|------|------|
| 7.1 | 核心框架完整 | 缺失关键步骤 | 有但不全 | 与原文一一对应 |
| 7.2 | 概念定义准确 | 有错误/篡改 | 基本准确 | 与原文一致 |
| 7.3 | 步骤数量匹配 | 严重缺失 | 有遗漏 | 完整覆盖 |
| 7.4 | 无自行删减关键内容 | 有关键删减 | 有小删减 | 无删减 |
| 7.5 | 示例与方法论一致 | 矛盾 | 基本一致 | 完整体现方法论 |

> 注：未提供原始方法论文档时，本维度标注"无法评估"。

## D8 规范符合度（10%）

| # | 检查项 | 0 分 | 3 分 | 5 分 |
|---|--------|------|------|------|
| 8.1 | frontmatter 只有 name + description | 有多余字段 | — | 合规 |
| 8.2 | SKILL.md 长度合理（< 500 行） | 超长 | 略长 | 精简，细节在 references |
| 8.3 | 使用 progressive disclosure | 所有内容在主文件 | 部分拆分 | 主文件+references 合理拆分 |
| 8.4 | references 文件都被索引 | 有孤立文件 | 部分索引 | 全部索引且说明何时读取 |
| 8.5 | 文件命名规范 | 混乱 | 基本规范 | 统一 kebab-case |
| 8.6 | 无冗余文件 | 有无关文件 | — | 干净 |
